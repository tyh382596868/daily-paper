## 一句话总结

> G³VLA 通过内参条件射线嵌入、投影位置编码（PRoPE）和双向跨视图融合，将标定相机几何信息注入 VLA 视觉 token 流，在 LIBERO 上平均提升 3.5%，无需修改骨干网络或动作空间。

---

## 核心贡献

1. **几何感应偏置注入**: 在视觉 token 级别引入[[相机内参]]条件的射线嵌入，将像素坐标映射为归一化投影射线，无需修改预训练骨干或动作解码器
2. **PRoPE 跨视图融合**: 提出基于投影位置编码的[[双向注意力机制|双向跨视图融合]]，利用相机内外参编码多视图几何关系，取代纯外观相似性的位置信号
3. **无深度传感器的几何蒸馏**: 利用 [[π³X]] 置信门控预测作为教师信号，通过两阶段训练课程在无真值深度时恢复大部分几何收益

## 问题背景

### 要解决的问题

现有 [[VLA|Vision-Language-Action]] 模型（RT-2、OpenVLA、[[π₀]]、[[GR00T N1.5|GR00T]]）沿用了预训练视觉-语言骨干的 2D 图像 token 接口。在多相机机器人操作系统中，相机内参 $K^v$ 和外参 $T^v$ 虽然已知，却完全未被利用——模型必须从动作监督中**隐式**学习空间关系，导致在需要精确空间推理的任务（物体定位、空间关系判断）上表现受限。

### 现有方法的局限

- **3D 显式表示方法**（PerAct、RVT、Act3D、PolarNet）：需要修改策略接口，引入体素化或点云等新输入模态，与现有 VLA 骨干不兼容
- **空间感知 VLA 方法**（3D-VLA、SpatialVLA、3DS-VLA）：依赖显式 3D 传感器输入或大规模空间预训练，部署成本高
- **相机感知表示**：PRoPE 等工作已证明几何位置编码的价值，但尚未系统集成到 VLA token 流水线

### 本文的动机

通过**最小改动**（仅修改视觉 token 的几何条件化方式）为 VLA 注入标定几何感应偏置，保留预训练骨干的视觉-语言知识，同时提升空间推理能力。几何信息作为归纳偏置而非新模态注入，与现有 [[Imitation Learning]] 目标完全兼容。

## 方法详解

### 模型架构

G³VLA 采用**插件式几何模块**架构，将几何感知嵌入到现有 VLA 的视觉 token 流中：

- **输入**: 语言指令 $l$ + 本体感觉状态 $s_t$ + 多视图 RGB 图像 $\{I_t^v\}_{v=1}^V$ + 相机参数 $\{K^v, T^v\}_{v=1}^V$
- **Backbone**: 预训练 [[SigLIP]] ViT（冻结骨干权重）
- **几何模块 $F_\psi$**: 射线嵌入 + PRoPE 双向跨视图融合
- **辅助预测头**: 预测每像素射线坐标和对数深度（训练用，推理可选）
- **输出**: 动作块 $a_{t:t+H-1}$（与原始 VLA 相同）

策略的完整预测接口：

$$
\pi_{\theta}(a_{t:t+H-1} \mid l, s_t, \{I_t^v, K^v, T^v\}_{v=1}^{V})
$$

几何模块对视觉 token 的变换：

$$
h_{1:P}^{1:V} = F_{\psi}(z_{1:P}^{1:V}, \{K^v, T^v\}_{v=1}^{V})
$$

**符号说明**:
- $z_{1:P}^{1:V}$: SigLIP 编码器输出的 patch token，$P$ 个 patch，$V$ 个视图
- $h_{1:P}^{1:V}$: 几何条件化后的视觉 token
- $K^v \in \mathbb{R}^{3\times3}$: 第 $v$ 个相机的内参矩阵
- $T^v$: 第 $v$ 个相机的相机到世界变换矩阵

### 核心模块

#### 模块 1: 内参条件射线嵌入（Ray Embeddings）

**设计动机**: 利用[[相机内参]]将每个 patch 的像素坐标映射为归一化投影射线，为每个视觉 token 提供"局部观察方向"信息，无需显式深度。

**具体实现**:
- 对像素坐标 $u = (x, y, 1)^\top$，用相机内参 $K^v$ 计算归一化投影射线：
  - $\tilde{r}^v(u) = (K^v)^{-1} u$
  - 射线坐标取前两维：$R^v(x,y) = [\tilde{r}^v(x,y,1)]_{1:2} \in \mathbb{R}^2$
- 可学习函数 $G_\phi$ 将射线坐标图投影到 patch 网格，以加法形式注入 SigLIP 输出 token：$z_{0,p}^v = z_p^v + G_\phi(R^v)_p$
- $G_\phi$ **零初始化**，确保训练初期不破坏预训练特征

**效果**: 消融实验中去除射线嵌入导致 LIBERO 平均下降 2.0%，是单个贡献中影响最大的组件。

#### 模块 2: 投影位置编码（PRoPE）

**设计动机**: [[PRoPE]] 基于相机内参 $K^v$ 和相机姿态 $T^v$ 推导跨视图投影变换作为固定位置信号，替代基于外观相似性的位置匹配。

**具体实现**:
- PRoPE 为跨视图注意力的 Query、Key、Value 表示参数化固定投影变换
- 使用 per-view 内参 $K^v$、相机到世界矩阵 $T^v$ 和 patch 位置推导变换
- 赋予跨视图注意力访问基于相机模型的投影关系，而非依赖外观

**效果**: 单独去除 PRoPE 导致下降 1.1%，与射线嵌入形成互补。

#### 模块 3: 双向跨视图融合（Bidirectional Cross-View Fusion）

**设计动机**: 让不同相机视图的视觉 token 相互交换几何上下文，实现多视图空间一致性。

**具体实现**:
融合函数 $H = \mathrm{Fusion}_\psi(Z; \{K^v, T^v\}_{v=1}^V)$ 分两步执行：

1. **帧内注意力（Frame Attention）**: 在每个相机流内独立处理 token
2. **跨视图注意力（Cross-View Attention）**: 将所有视图和 patch 维度展平，实现双向 token 交互；使用 PRoPE 作为位置信号；无效视图在两个注意力阶段均被 mask 掉

#### 模块 4: 辅助几何预测头

附加在融合 token 上，对每个像素预测：
- 射线坐标：$\hat{q}_u^v \in \mathbb{R}^2$
- 对数深度：$\hat{d}_u^v \in \mathbb{R}$

仅用于提供几何监督，不参与最终动作预测。

## 关键公式

### 公式 1: [[归一化投影射线|射线坐标计算]]

$$
R^v(x,y) = [\tilde{r}^v(x,y,1)]_{1:2}, \quad \tilde{r}^v(u) = (K^v)^{-1}u
$$

**含义**: 将像素坐标 $(x,y)$ 通过相机内参逆矩阵反投影为归一化射线坐标，编码每个 patch 的观察方向。

**符号说明**:
- $K^v$: 第 $v$ 视图的相机内参矩阵（焦距、主点）
- $u = (x, y, 1)^\top$: 齐次像素坐标
- $\tilde{r}^v(u) \in \mathbb{R}^3$: 归一化射线方向（单位化前）
- $[\cdot]_{1:2}$: 取向量前两个分量

### 公式 2: [[可学习射线嵌入|射线嵌入注入]]

$$
z_{0,p}^v = z_p^v + G_\phi(R^v)_p
$$

**含义**: 可学习嵌入函数 $G_\phi$ 将射线坐标图以加法形式注入到 SigLIP 编码器输出的第 $p$ 个 patch token。

**符号说明**:
- $z_p^v$: SigLIP 输出的第 $v$ 视图第 $p$ 个 patch token
- $G_\phi$: 零初始化的可学习嵌入函数
- $R^v$: 射线坐标图（包含所有 patch 位置的射线方向）

### 公式 3: [[Cross-View Attention|跨视图融合]]

$$
H = \mathrm{Fusion}_\psi(Z; \{K^v, T^v\}_{v=1}^{V})
$$

**含义**: 利用 PRoPE 位置编码进行双向跨视图融合，使不同相机视图的视觉 token 相互交换几何上下文。

### 公式 4: [[置信门控|π³X 置信门控]]

$$
m_u^v = \mathbf{1}[\sigma(c_u^v) > \tau], \quad \tau = 0.1
$$

**含义**: 对教师模型 [[π³X]] 的深度预测按置信度阈值进行硬门控，仅保留高置信度像素的预测用于蒸馏。

**符号说明**:
- $c_u^v$: π³X 在第 $v$ 视图第 $u$ 像素的原始置信度 logit
- $\sigma(\cdot)$: Sigmoid 函数
- $\tau = 0.1$: 置信度阈值
- $m_u^v \in \{0, 1\}$: 二值掩码

### 公式 5: [[几何蒸馏损失|蒸馏损失]]

$$
\mathcal{L}_{\mathrm{distill}} = \frac{\sum_{v,u} m_u^v \left(\frac{1}{2}\|\hat{q}_u^v - q_u^v\|_2^2 + (\hat{d}_u^v - d_u^v)^2\right)}{\sum_{v,u} m_u^v + \epsilon}
$$

**含义**: 加权回归损失，对射线坐标（L2 范数）和对数深度（均方误差）同时监督，权重由置信门控掩码决定。

**符号说明**:
- $\hat{q}_u^v \in \mathbb{R}^2$: 预测的射线坐标
- $q_u^v$: 真值（GT 或 π³X 预测）射线坐标
- $\hat{d}_u^v$: 预测的对数深度
- $d_u^v$: 真值对数深度
- $\epsilon$: 数值稳定项

### 公式 6: [[两阶段训练|组合训练损失]]

$$
\mathcal{L} = \lambda_{\mathrm{act}} \mathcal{L}_{\mathrm{act}} + \lambda_{\mathrm{distill}} \mathcal{L}_{\mathrm{distill}}
$$

**含义**: 动作模仿损失与几何蒸馏损失的加权组合，通过两阶段训练课程调整权重比例。

**符号说明**:
- $\lambda_{\mathrm{act}}$: Stage 1 = 0.1，Stage 2 = 1.0
- $\lambda_{\mathrm{distill}}$: Stage 1 = 1.0，Stage 2 = 0.05
- $\mathcal{L}_{\mathrm{act}}$: VLA 的动作预测损失（模仿学习目标）

## 实验

### 数据集

| 数据集 | 特点 | 用途 |
|--------|------|------|
| LIBERO（Goal/Spatial/Object/L-10） | 4 个子套件，含空间/物体/目标敏感任务 | 主要仿真基准 |

### 实现细节（两阶段训练）

| 参数 | Stage 1（几何预训练） | Stage 2（完整微调） |
|------|------|------|
| 训练步数 | 5,000 步 | 30,000 步 |
| 骨干状态 | 冻结 | 全参数解冻 |
| $\lambda_{\mathrm{act}}$ | 0.1 | 1.0 |
| $\lambda_{\mathrm{distill}}$ | 1.0 | 0.05 |
| 学习率 | $2.5 \times 10^{-5}$（初始） | $2.5 \times 10^{-5} \to 2.5 \times 10^{-6}$（余弦衰减） |
| Warmup | 500 步 | 1,000 步 |
| 学习率调度 | 余弦衰减 | 余弦衰减 |

Stage 1 以几何学习为主导，防止早期干扰动作学习；Stage 2 中蒸馏损失作为轻量正则化项。

## 批判性思考

### 优点

1. **最小侵入性**: 仅修改视觉 token 级别的几何条件化，不改变骨干架构、动作空间或模仿学习目标，易于移植到任意 VLA
2. **无深度传感器依赖**: 通过 [[π³X]] 置信门控蒸馏，在仅有 RGB 和相机标定参数时仍能获得几何增益
3. **空间任务针对性强**: Object（+5.0%）和 Spatial（+4.0%）套件的不均匀提升验证了几何偏置的有效性假设
4. **真实机器人 OOD 泛化**: 分布外相机视角下的显著改进（OOD 倒坚果：70.8% → 83.3-87.5%）表明几何信息有助于跨视角泛化

### 局限性

1. **架构依赖性**: [[GR00T N1.5|GR00T]] 1.5 的双塔架构中，几何 token 须额外经过注意力瓶颈才能到达动作通路，显著削弱了几何信号
2. **π³X 领域敏感**: π³X 作为深度教师在清洁合成环境（RoboTwin2.0）下与 GT 差距最大（-8.0%），说明教师质量受领域匹配影响
3. **需要相机标定**: 方法依赖已知 $K^v$ 和 $T^v$，对无标定相机或相机参数动态变化的场景不适用
4. **增益有限于饱和骨干**: 在 [[Pi05]] 等接近饱和的强骨干上收益（+1.1%）明显小于 [[π₀]] 基础版（+3.5%）

### 潜在改进方向

1. 针对双塔 VLA 架构设计更直接的几何信息注入路径（绕过注意力瓶颈）
2. 探索更鲁棒的无深度传感器几何教师，减少对 π³X 领域匹配的依赖
3. 扩展到无相机标定参数的场景（通过在线标定或自监督几何学习）
4. 将几何感应偏置扩展到动态相机配置（如手持/移动相机）
