# FLARE

## 定义

Future Latent Representation Alignment — 潜空间世界建模的代表，**对齐动作去噪过程与未来表征**，但不显式生成视频。

## 核心要点

1. [[RobotWM-Survey]] Section 3.6 中"潜空间 WM"范式的代表
2. 避免视频解码的算力开销，同时让策略隐式利用未来预测结构
3. 与 [[VLA-JEPA]]、JEPA-VLA 同属"不解码像素"路线
4. 是 [[JEPA]] 思想在机器人策略中的应用
