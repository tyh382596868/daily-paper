# WorldOlympiad

## 定义
Alibaba 提出的视频世界模型诊断 benchmark，从物理真实性、几何一致性、交互保真度三轴系统评测 WM 能力。

## 核心要点
1. 三轴评测：物理真实性 + 几何一致性 + 交互保真度
2. 对比 Cosmos-Predict、LongLive、WorldPlay、Matrix-Game 等主流 WM
3. 使用 CLIP 和 MLLM 评分框架
