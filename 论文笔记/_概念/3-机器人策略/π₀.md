# π₀（pi0）

## 定义

π₀ 是 Physical Intelligence 公司提出的机器人基础模型，首次将 Flow Matching 扩散策略与视觉-语言模型结合，实现高性能通用机器人控制。

## 核心要点

1. 使用 Flow Matching 生成连续动作，优于离散 token 方法
2. 在 LIBERO 上平均 94.2%，是 π₀.₅ 和 MolmoAct2 的前置工作
3. 闭源，训练数据不公开
