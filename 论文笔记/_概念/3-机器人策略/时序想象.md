# 时序想象 (Temporal Imagination)

## 定义

**Temporal Imagination** 是 [[MemoryVLAPP|MemoryVLA++]] 新增的前向时序建模模块：以当前工作记忆、[[感知-认知记忆库|PCMB]] 历史和动作意图为条件，生成式地预测未来 $k$ 步的观测表征 $\hat{o}_{t+1:t+k}$，与历史记忆共同为 [[扩散动作专家|Diffusion Action Expert]] 提供**双向时序上下文**（回顾历史 + 前瞻未来）。

## 核心思路

类比人类的**心智模拟**（Mental Simulation）：执行复杂操作任务时，人类不仅依赖历史记忆，还会在心智中预演未来场景（如想象物品被放置后的位置）。Temporal Imagination 在模型层面实现这一能力，与 PCMB 的"回顾"形成**双向时序建模**。

## 核心要点

1. **前向预测**：生成未来观测表征，非像素级重建，而是语义表征空间的预测
2. **双向互补**：PCMB 提供历史（Retrospective），Imagination 提供前瞻（Prospective）
3. **条件化动作生成**：$[\tilde{p}_t, \tilde{c}_t, \hat{o}_{\text{imag}}]$ 共同条件化扩散动作专家
4. **误差传播风险**：想象预测在分布外场景可能引入错误先验
