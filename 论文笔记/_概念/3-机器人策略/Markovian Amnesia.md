# Markovian Amnesia

## 定义

[[反应式策略]]（基于当前观测独立决策）在需要长程记忆的任务上出现的失效模式：每一步都"忘掉"之前的事情，无法处理目标遮挡、多目标顺序、中途意图变化等需要历史推理的场景。

## 核心要点

1. 由 $\pi(a_t \mid o_t)$ 假设直接导致——条件分布不含 $a_{<t}, o_{<t}$；
2. 典型失败模式：在 PushT2 中震荡于两个目标之间、Stack3 中遮挡后忘记电池位置；
3. [[Action Chunking]] 部分缓解（块内有时序），但跨块仍有遗忘；
4. 解决方案：[[MemoryVLA]]（外挂记忆）、[[AR-VLA]]（KV cache 内嵌历史）、[[历史条件化策略]]。

## 代表工作

- [[AR-VLA]]：明确命名并用 PushT2 / Stack3 任务验证
