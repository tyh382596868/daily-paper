# AnyGrasp

## 定义

一种通用 6-DoF 抓取姿态估计方法，能在任意物体、任意场景下输出可行抓取，常用作机器人数据生成流水线中的自主抓取模块。

## 核心要点

1. 输入单视角点云 / RGB-D，输出 6-DoF 抓取候选 + 置信度
2. 通用类别无关（class-agnostic），不需要物体的 3D 模型
3. 在仿真数据流水线中常作为闭环执行的「执行器」，配合 [[VLM]] 任务分解实现规模化数据生成
4. 闭环重试：失败抓取触发重新采样 + 重试

## 代表工作

- [[RoboMemArena]]: 用 AnyGrasp 作为数据流水线第二阶段的自主执行器
