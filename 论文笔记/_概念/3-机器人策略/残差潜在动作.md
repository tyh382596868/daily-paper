# 残差潜在动作

## 定义

残差潜在动作（Residual Latent Action, RLA, Zhang et al., 2026）是一种从 [[DINO]] patch token 的**帧间残差** $s_{t+h}-s_t$ 中学到的紧凑潜变量表征。它由一个轻量自编码器学得（编码器吃残差、解码器吃 $(z, s_t)$ 单次前向还原 $s_{t+h}$），用作[[世界模型]]的预测目标，把高维特征预测问题转化为低维转移表征生成问题。

## 数学形式

$$
z = f_{enc}(s_{t+h} - s_t), \qquad \hat{s}_{t+h} = f_{dec}(z,\, s_t)
$$

$$
\mathcal{L}_{AE} = \lVert s_{t+h} - \hat{s}_{t+h} \rVert_1 + \lVert s_{t+h} - \hat{s}_{t+h} \rVert_2^2
$$

## 核心要点

1. **预测充分性**：即便 $|z|$ 小到 64，解码器也能高保真还原 1024×1024 维的 DINO token $s_{t+h}$；远好于 [[AdaWorld]]（$|z|=2048$）、[[UniVLA]]（$|z|=256$）。
2. **可泛化性**：只在有限的 [[ManiSkill]] 数据上训练 RLA 自编码器，即可零样本迁移到训练时没见过的机器人本体/交互（如 Panda → XArm+Robotiq）。
3. **时间拓扑性**：归一化后的 RLA $\bar z$ 与高斯噪声 $\epsilon$ 之间线性插值再解码，$(\epsilon+\bar z)/2$ 近似得到时间中点帧 $s_{t+h/2}$，说明 RLA 空间内蕴含时间进度结构。
4. **动机**：DINO token 帧间变化局部、残差信息量远小于 token 本身——这是典型的"维度灾难"减负，世界模型只需在低维空间生成 $z$，再用解码器一步还原。
5. **下游用途**：可作为 BC 策略的辅助监督头（从无动作视频学策略），也可作为世界模型内 RL 的状态预测目标。
