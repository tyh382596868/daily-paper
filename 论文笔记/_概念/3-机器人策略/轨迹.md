# 轨迹

## 定义

机器人在一次任务中的状态-动作序列 $\tau = \{(s_t, a_t)\}_{t=1}^T$，通常与对应观测视频 $o_{1:T}$ 一起构成一条「演示」(demonstration)。

## 数学形式

$$
\tau = \{(s_t, a_t)\}_{t=1}^{T}, \qquad o_{1:T} = \{o_t\}_{t=1}^{T}
$$

## 核心要点

1. $s_t$ 通常是关节角 / 末端位姿；$a_t$ 是 delta 末端位姿或关节速度等
2. 在模仿学习中，策略学的是 $\pi(a_t \mid o_{1:t}, \ell)$
3. 在世界模型合成中（如 [[RoboDream]]），$\tau$ 可被复用 — 一份 $\tau$ 配不同 $(I_s, I_o)$ 生成多条新 $o_{1:T}$
4. 是 [[Action Chunking]]、[[Diffusion Policy]] 训练目标的最小单元

## 代表工作

- [[Diffusion Policy]] / [[ACT (Action Chunking Transformer)|ACT]]: 经典模仿学习
- [[RoboDream]]: 用 retrieval 复用 [[DROID]] 中的 $\tau$
