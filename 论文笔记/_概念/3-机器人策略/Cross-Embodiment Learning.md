# Cross-Embodiment Learning

## 定义

跨本体学习是机器人学习中的一个范式，目标是使在一种机器人本体（形态、自由度、末端执行器）上学到的策略或表示能够迁移、复用或辅助另一种本体的学习，从而克服每个本体都需要独立大规模数据采集的瓶颈。

## 数学形式

设本体集合 $\mathcal{R} = \{R^{(1)}, \ldots, R^{(K)}\}$，各本体动作空间 $\mathcal{A}^{(i)}$ 互不相同。跨本体学习目标是找到共享表示空间 $\mathcal{Z}$ 与映射 $\phi^{(i)}: \mathcal{A}^{(i)} \to \mathcal{Z}$，使得在 $\mathcal{Z}$ 上训练的单一策略 $\pi: \mathcal{O} \to \mathcal{Z}$ 可控制所有本体。

## 核心要点

1. **动作空间异构性**: 不同末端执行器（灵巧手 vs 平行夹爪）的动作维度和语义差异巨大，直接混合训练效果差
2. **数据复用**: 跨本体学习的核心价值是减少每个新本体的数据采集需求
3. **对齐策略**: 常用方法包括共享隐空间（对比学习）、姿态重定向（Retargeting）、共享视觉特征等
4. **人-机器人迁移**: 人手演示数据是重要的跨本体数据来源，需要重定向到机器人关节空间
