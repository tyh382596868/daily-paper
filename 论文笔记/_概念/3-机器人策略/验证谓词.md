# 验证谓词

## 定义

机器人 benchmark 中用于判断「子任务是否完成」的**状态谓词函数** $\psi(s)$，对状态空间 $s$ 返回二值真/假；通常由仿真器的 state oracle 提供，是计算 [[任务成功率|TSR]] 与 [[累积成功率|CSR]] 的基础。

## 核心要点

1. 形式化标注子任务完成条件，如 "object_A in container_B"、"button_pressed_count == 3"
2. 由仿真器 state oracle 提供，不依赖学习
3. 每个任务包含多个谓词（[[RoboMemArena]] 中每任务 3–9 个）
4. 是构建多阶段评估的核心机制

## 代表工作

- [[RoboMemArena]]: 每任务 3–9 个验证步骤，平均 5.8
