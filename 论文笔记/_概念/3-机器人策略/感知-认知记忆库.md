# 感知-认知记忆库 (PCMB)

## 定义

**Perceptual-Cognitive Memory Bank (PCMB)** 是 [[MemoryVLA]] 提出的双通道持久记忆模块，受海马体（Hippocampus）启发，分别存储低层感知细节和高层语义认知信息，支持 [[VLA]] 机器人在长程非马尔科夫任务中检索历史状态。

## 核心结构

- **感知通道**: 由 DINOv2 + SigLIP 提取的图像感知 Token，经 SE-bottleneck 压缩至 256 维，捕捉低层视觉细节
- **认知通道**: 由 LLaMA-7B VLM 生成的隐层 Token，投影为高层语义表征
- **工作记忆查询**: 当前时刻的感知/认知 Token（短时工作记忆）通过**带时序位置编码的跨注意力**检索 PCMB
- **门控融合**: $\tilde{x} = g_x \odot H_x + (1-g_x) \odot x$，自适应融合历史上下文与当前表征
- **Token-merge Consolidation**: 超容量时合并余弦相似度最高的相邻条目，维持 PCMB 紧凑

## 核心要点

1. 双通道分离存储，感知细节与语义摘要互补，适应不同检索需求
2. 时序位置编码（Sinusoidal PE）注入时序信息，提升检索的时序感知
3. 门控融合优于简单加法，Consolidation 优于 FIFO，消融实验验证
4. PCMB 容量固定，长程任务（>1000 步）中早期信息有压缩损失风险
