# 可学习射线嵌入

## 定义

可学习射线嵌入是将相机内参条件化的[[归一化投影射线]]坐标通过可学习函数映射为与视觉 patch token 维度相同的向量，以加法形式注入预训练视觉编码器输出，为每个 token 附加"局部观察方向"的几何信息。

## 数学形式

$$
z_{0,p}^v = z_p^v + G_\phi(R^v)_p
$$

其中射线坐标：

$$
R^v(x,y) = [(K^v)^{-1}(x,y,1)^\top]_{1:2} \in \mathbb{R}^2
$$

## 核心要点

1. $G_\phi$ **零初始化**：训练初期不改变预训练特征，逐渐学习注入几何信息
2. 不同相机（不同 $K^v$）产生不同的射线坐标，使嵌入具有内参感知能力
3. 以加法形式注入，不修改骨干架构，与预训练特征协同而非替代
4. 消融实验中去除射线嵌入导致 LIBERO 下降 2.0%，是最关键的单一组件

## 代表工作

- [[G3VLA]]: 提出并验证了内参条件射线嵌入在 VLA 多相机设置中的有效性
