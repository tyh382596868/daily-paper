# 两级几何锚定

## 定义

在训练期用两层冻结的几何教师把 [[VLA]] 模型中的场景表征 / [[递归场景前缀|场景槽]] 锚定到真实 3D 几何，避免端到端梯度让 token 塌成无几何含义的潜变量。**部署期不需要任何教师**。

两层结构：
- **局部锚（Local Anchor）**: 跨视图掩码深度重建，监督来自冻结的 [[MoGe-2|单目深度教师]] / LingBot-Depth
- **全局锚（Global Anchor）**: 通过视图条件解码器对齐到冻结的 [[Pi3X|3D 基础模型]] 的多视图 3D 表征

## 数学形式

**局部锚** — [[SmoothL1 Loss|SmoothL1]] 跨视图深度重建：

$$
\mathcal{L}_{\text{geo}} = \frac{1}{V}\sum_{i=1}^{V} \mathrm{SmoothL1}\!\left(\hat{f}^d_{t,i},\; f^d_{t,i}\right)
$$

**全局锚** — L1 表征对齐：

$$
\mathcal{L}_{\text{rep}} = \frac{1}{V}\sum_{v=1}^{V}\big\| P_t^{(v)} - Z_t^{(v)} \big\|_1, \quad Z_t = \mathrm{3DFM}(x_t)
$$

## 核心要点

1. **教师全部冻结**: 不需要 3D label，所有几何监督都来自 off-the-shelf 模型
2. **掩码 + 跨视图重建**: 强制场景槽真正聚合多视角几何，而不是 shortcut 到单视图特征
3. **局部 + 全局互补**: 局部关注像素级深度，全局关注 token-level 3D 表征
4. **部署期 0 代价**: MDT 和 3DFM 都只在训练梯度里出现
5. **核心约束**: 上限受教师质量限制（[[Pi3X]] 在 occluded 场景误差大 → 学不到比教师更准的几何）

## 代表工作
