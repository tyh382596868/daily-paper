# 动态操作

## 定义

机器人[[操作]]任务的一个子类，其特征是**场景在策略执行过程中持续变化**，目标物体可能在移动（传送带、滚动、抛投）。与传统的"静态操作"假设场景准静态正好相反。

## 典型任务

| 类别 | 例子 |
|------|------|
| 传送带任务 | 抓取传送带上经过的物体 |
| 抛物拦截 | 接住空中飞来的物体 |
| 滚动物体抓取 | 在斜坡上滚动的小球 |
| 桨板击球 | 用末端工具击中移动目标 |
| 双臂协同 | 一臂移动物体时另一臂操作 |

## 难点

1. **感知-行动延迟**: VLA 决策时刻看到的画面已经过时
2. **运动学预测**: 需要估计物体未来位置
3. **实时性约束**: 通常要求 5-10 Hz 决策频率
4. **物理参数不确定**: 摩擦、空气阻力等难以建模

## 现有方法

- **传统 [[MPC]]**: 需要精确动力学模型
- **学习式视觉伺服**: 高频反馈但视野有限
- **[[VLA]] + 世界模型**: [[AHEAD]] 这类方法

## 代表基准

- [[AHEAD]] 提出的 Dynamic-Sim Suite（20 任务）
- BackFlip 等 RL benchmark

## 反例

主流 [[VLA]]（[[OpenVLA]], [[RT-2]], [[Octo]]）在动态任务上成功率 < 60%；真机抛物拦截类任务基线常常是 0/30。
