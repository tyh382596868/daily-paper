# RTC（Runtime Correction）

## 定义

一种**无需重训模型**的异步 VLA 推理补偿方法，通过在推理时对生成的动作块进行动作内插（action inpainting），平滑块与块之间的边界不连续性。

## 核心要点

1. **无训练成本**: RTC 不修改模型权重，纯粹在推理阶段对动作序列做后处理。
2. **内插修复**: 在新旧动作块交接处，用内插算法填补由推理延迟引入的边界跳跃。
3. **代价**: 额外的后处理计算使端到端延迟从约 73ms 增加到 159ms，控制频率从 13.6Hz 降至 6.28Hz。
4. **局限**: 只做事后修补，无法让模型真正「感知」延迟情境，对大延迟场景效果有限。

## 与 ACNet 的对比

| 维度 | RTC | ACNet |
|------|-----|-------|
| 成功率 (Kinetix avg) | 0.72 | 0.79 |
| 延迟 (Meta-World) | 159ms | 91ms |
| 控制频率 | 6.28Hz | 11.0Hz |
| 训练参数 | 0% | ~20% |

## 代表工作

- [[ACNet]]: 以 RTC 为主要对比基线，在成功率和实时性上均超越 RTC
