# π0.5

## 定义

π0.5 是 Physical Intelligence（PI）发布的大型视觉-语言-动作（VLA）模型，在 π0 基础上进一步扩展，支持更复杂的长程操作任务和更强的语言指令理解能力。

## 核心要点

1. **闭源模型**: 权重未完全公开，研究中通常使用 LeRobot 社区提供的开放权重版本进行对比
2. **VLA 架构**: 将视觉、语言和动作预测统一在一个大型 Transformer 中
3. **泛化能力**: 通过大规模预训练和 MT50 微调具备一定跨任务能力
4. **在 VICX 中作为基线**: π₀.₅-Finetune 在 Meta-World MT50 微调后与 VICX 对比，VICX 以更少训练数据超越

## 代表工作

- [[π0]]: 前驱模型
- [[VICX]]: 与 π₀.₅-Finetune 基线对比，成功率超越
