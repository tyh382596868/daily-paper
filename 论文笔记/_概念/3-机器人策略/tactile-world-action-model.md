# Tactile World Action Model

## 定义
将触觉传感信号（tactile sensor 输出）纳入世界动作模型框架，联合预测未来的视觉和触觉状态，从而为 contact-rich 操作提供物理感知增强。

## 核心要点
1. 视觉+触觉联合预测，学习接触物理表示
2. 支持"tactile dreaming"：预测触觉序列作为数据增强
3. 针对插接、可变形物体操作等任务
