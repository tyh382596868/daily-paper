# 层级门控融合

## 定义

层级门控融合（Layer-wise Gated Fusion）是一种将 [[VLM]] 中间层特征逐层注入[[Action Expert|行动专家]]的机制：在行动专家的每个 Transformer 层输入处，通过可学习标量 sigmoid 门控残差叠加来自 [[Qwen3-VL]] 等骨干网络对应深度的中间特征，使行动专家同时获取浅层空间信息和深层语义信息。

## 数学形式

$$
h_\text{in}^{(i+1)} = h_\text{out}^{(i)} + \sigma(\hat{w}_i) \cdot \phi_i^{\text{VLM}}(v,\ell)
$$

其中 $\hat{w}_i$ 为第 $i$ 层可学习标量门控参数，$\sigma(\cdot)$ 为 Sigmoid，$\phi_i^{\text{VLM}}$ 为 VLM 第 $i$ 个等间隔深度的中间特征。

## 核心要点

1. **均匀采样**: 从 VLM 的等间隔深度位置采样 $N$ 个中间层特征，覆盖浅层空间和深层语义
2. **可学习门控**: 标量 $\hat{w}_i$ 初始化为负值（门初始接近 0），训练中逐渐开放，避免初期过度干扰先验
3. **第 0 层初始化**: $h_\text{in}^{(0)} = \phi_0^{\text{VLM}}(v,\ell)$，直接使用 VLM 输入嵌入
4. **对比 Token Insertion**: 优于直接插入语言 token 的方式，特别在 OOD 未见对象/环境场景下差异显著

## 代表工作

- [[APT]]: 首次提出层级门控融合，用于将 Qwen3-VL 特征注入扩散行动专家，解决 VLA OOD 语言泛化问题
