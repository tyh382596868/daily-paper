# 非马尔可夫任务（Non-Markovian Tasks）

## 定义

当前状态不足以唯一确定最优动作的任务：正确决策依赖于历史状态序列或未来预期，违反了马尔可夫假设（Markov Property，即"当前状态包含所有决策所需信息"）。

## 核心要点

1. **马尔可夫假设的局限**：大多数 VLA 模型假设单帧观测即可决策，但真实操作任务往往需要知道"过去发生了什么"
2. **典型场景**：长程操作任务（如"把刚才拿走的杯子放回原位"）、需要顺序记忆的任务（如依次完成多个子目标）
3. **应对方案**：历史帧拼接、RNN/LSTM、外部记忆库（如 [[Perceptual-Cognitive Memory Bank]]）、状态估计器

## 代表工作
