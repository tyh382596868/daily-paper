# GR00T

## 定义

GR00T（Generalist Robot 00T）是 NVIDIA 发布的通用机器人基础模型系列，采用双塔架构（语言/视觉塔 + 动作塔），通过大规模预训练支持多种机器人操作任务。

## 核心要点

1. **双塔架构**：VLM 塔处理视觉-语言输入，动作塔生成机器人动作；两塔通过跨注意力瓶颈连接
2. **双塔的局限**：几何感知 token 须经过额外的注意力瓶颈才能到达动作通路，可能削弱几何信号（G³VLA 观测到效果衰减）
3. **版本**：GR00T N1.5（LIBERO 基准，94.9% 平均）、GR00T N1.7 等
