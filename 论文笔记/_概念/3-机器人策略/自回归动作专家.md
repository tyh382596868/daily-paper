# 自回归动作专家

## 定义

一种在**时间维度**真正自回归的动作生成模块：动作 $a_t$ 显式依赖完整历史 $a_{<t}, s_{<t}$ 与最新 VL 前缀，每步只生成一个连续动作 token，区别于"块自回归"或"反应式快照"范式。

## 数学形式

$$
P_{\text{ar}}(\tau) = \prod_{t=1}^{T} P\big(a_t \mid \Phi(v_i, l),\, a_{<t}, s_{<t}\big), \quad i \le t
$$

## 核心要点

1. 与"伪自回归" [[VLA]]（仅在单步 token 内 AR）相对，强调**跨时间步**的因果依赖；
2. 通过 KV cache 维护历史，每步只 push 一个 token；
3. 配合 [[Hybrid KV Cache]] 让 VLM 异步刷新前缀；
4. 解决 [[Markovian Amnesia]]，提升时序平滑度。

## 代表工作

- [[AR-VLA]]：首次把"真正跨时间 AR"作为 VLA 设计原则，配套 HKV + DTR + 两阶段训练
