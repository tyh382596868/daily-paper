# 双系统架构 (System 1 / System 2)

## 定义

源于 Kahneman 思想的双系统决策范式：**System 1 (S1)** 快速、低层、反射式；**System 2 (S2)** 慢速、高层、深思熟虑。在 [[VLA]] 设计中常实例化为「低频 [[VLM]] 规划器 + 高频动作策略」的异步耦合架构。

## 核心要点

1. **频率分离**: S2 慢（≤2 Hz）做规划、检索、子任务切换；S1 快（≥3 Hz）出动作
2. **异步执行**: S2 在算的时候 S1 不卡，常用 ratio 设计（如 2.92:1）
3. **职责分离**: S2 处理记忆、检索、推理；S1 处理感知-动作循环
4. 这种范式天然适合**长程记忆任务**

## 代表工作

- [[MemER]]: 双系统 + 关键帧检索
- [[PrediMem]]: 双系统 + [[预测编码头]] + 显式 [[关键帧记忆库]]
- 早期 RT-2 / Gemini Robotics / Helix 等也属于此范式
