# HiF-VLA

## 定义

一种 [[VLA]] 变体，同时建模 **hindsight（回顾）**、**insight（当下洞察）**、**foresight（前瞻）** 三种运动表征，希望通过多时间尺度的运动信号提升操作策略的连贯性。

## 核心要点

1. 三路时间表征联合训练：历史 / 当前 / 未来运动
2. 不针对显式记忆任务设计，主要处理反应式短程操作
3. 在长程记忆 benchmark 上表现弱于显式 memory 方法

## 代表工作

- [[RoboMemArena]] 中作为长程记忆任务的 baseline，平均 TSR 16.9%
