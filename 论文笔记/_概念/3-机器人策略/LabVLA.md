# LabVLA

## 定义
浙大/上海 AI Lab 提出的科学实验室 VLA，构建 LabEmbodied 数据集 + LabUtopia 仿真平台，针对精密仪器操作和液体处理任务。

## 核心要点
1. 三件套：LabEmbodied 数据集 + LabUtopia 仿真平台 + FAST+DiT VLA
2. 关键约束：演示数据必须从 physically executable 合法场景开始
3. 实验室场景 OOD 挑战：精密仪器、液体操作、罕见物体
4. 48 HF upvotes，真实机器人验证
