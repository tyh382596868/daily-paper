# 机器人操作（Robotic Manipulation）

## 定义

机器人学的核心问题之一：让机器人通过末端执行器（夹爪、灵巧手、吸盘等）与环境中的物体发生物理交互，完成抓取、放置、推拉、组装、倒水等任务。在具身智能背景下，往往与视觉、语言、动作的联合学习紧密相关，是 [[VLA]] 模型的核心评测场景。

## 核心要点

1. **典型任务族**:
   - **Pick-and-Place**: 抓取-放置（最经典）
   - **Articulated Object**: 开门、开抽屉、拧瓶盖
   - **Deformable Object**: 折毛巾、倒水、操控柔性物体
   - **Bimanual / Tool Use**: 双臂协同、工具使用
2. **关键挑战**:
   - **接触建模**: 接触动力学非光滑，仿真到现实差距大
   - **泛化**: 不同物体几何、材质、光照下的鲁棒性
   - **长时序**: 多步骤任务的子目标分解和恢复
3. **常用数据集**: [[DROID]], [[BridgeV2]], [[OXE]], [[LIBERO]], [[RoboCasa]], [[Metaworld]]
4. **常用 benchmark**: [[LIBERO]], [[Metaworld]], [[RoboCasa]], [[WorldArena]]
5. **典型方法**: [[Diffusion Policy]], [[ACT (Action Chunking Transformer)|ACT]], [[OpenVLA]], [[π₀]], [[π₀.₅]]
