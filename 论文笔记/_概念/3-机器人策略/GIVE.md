# GIVE (Grounding Human Gestures in VLA)

## 定义
NTU MARS Lab 提出的手势 grounding VLA，通过 VGP 模块将人类手势编码为 gesture token 注入 VLA。

## 核心要点
1. VGP（Visual Gesture Pretraining）：手势视频 → gesture token
2. 手势提供空间方向性信息，语言提供语义信息，互补
3. 适用于 HRI（人机交互）协作机器人场景
4. NTU HRI 数据集上验证
