# Multi-Goal 任务族

## 定义

[[AliasBench]] 的第四类任务：episode 早期出现一个**瞬时线索**（短暂的颜色 / 闪烁 / 提示物）确定目标，之后线索消失，机械臂在执行中观察到的当前帧不再含有目标信息。

## 核心要点

1. **典型例子**: 三个相同容器之一被短暂高亮，关掉之后要把物体送到那个容器
2. **混叠源**: 线索消失后所有候选目标外观相同
3. **解法**: 历史窗口必须覆盖到线索出现的时刻
4. **任务数量**: 3 个
5. **窗口长度限制**: 若线索出现在 $K$ 帧之前，[[IntentVLA]] 的固定窗口会失效，需要长期记忆

## 代表工作

- [[IntentVLA]]: 在 Multi-Goal 上从 8.7% 提升到 31.3%（+22.6 pp）
