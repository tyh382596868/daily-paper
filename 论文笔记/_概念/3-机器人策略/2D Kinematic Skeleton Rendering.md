# 2D Kinematic Skeleton Rendering

## 定义
将机器人或人体骨骼的 2D 投影图像作为视频生成模型的动作条件，提供跨具身一致的运动表示。

## 数学形式
$$c_{kin} = \text{Render2D}(J_{3D}, K)$$
其中 $J_{3D}$ 为 3D 关节位置，$K$ 为投影矩阵。

## 核心要点
1. 用 2D 骨架替代原始图像条件，降低具身差异带来的分布 gap
2. 骨架投影统一了不同机器人臂和人手的外观差异
3. 与 [[OSCAR]] 的跨具身世界模型结合

## 代表工作
- [[OSCAR]]: 采用 2D 骨骼渲染统一跨具身动作条件化
