# 模式坍塌（Mode Collapse）

## 定义

生成模型的经典失败模式：模型在面对不同输入条件时输出过于相似的结果，无法覆盖训练分布或条件分布的多样性。最早在 GAN 时代被广泛讨论，在视频[[世界模型]]时代以新形态重现——**不同 prompt 下的视频几乎相同**。

## 核心要点

1. **传统 GAN 视角**: 生成器把多种 latent code 都映射到少数几个高质量样本，丧失多样性。
2. **视频世界模型视角**: 不同 prompt 条件（例如 "dry asphalt" vs "icy road"）下，模型生成的视频在关键物理后果上几乎无差异；条件信号被忽略。
3. **常见诱因**:
   - 条件信号在视觉上**不显著**（例如表面摩擦改变了车辆减速度，但单帧视觉差异微弱）
   - 训练数据中该条件维度的样本稀疏，模型用平均行为覆盖
   - 文本编码器对细微物理描述的语义区分不足
4. **诊断**: 在 [[WhatIfWorld]] 中，Surface Friction 原语得分仅 14.2%，远低于视觉显著的 Force/Degree（40.4%），正是模式坍塌在视觉不显著维度上的体现。
