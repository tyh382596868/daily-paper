# 因果反转（Causal Inversion）

## 定义

视频生成 / [[世界模型]] 的一种失败模式：模型在接收反事实 prompt（如"重刹"）时，输出的视频展示了与 prompt 因果方向**完全相反**的物理后果（如"加速"）。说明模型并未真正理解 prompt 中动作描述的因果含义，可能在做训练分布检索而非物理推演。

## 核心要点

1. **典型表现**: prompt 说 "decelerates hard"，视频中车辆反而加速；prompt 说 "lift gently"，视频中物体反而被砸下去。
2. **成因猜想**:
   - 模型从训练分布中检索出"最常见的车辆运动"，忽略了动作描述的细节方向
   - 文本 encoder 对反义词（accelerate/decelerate）的语义区分不足
   - 缺乏因果训练信号，模型把"动作描述"当作风格条件而非物理指令
3. **检测方法**: 用反事实配对 prompt $(p^+, p^-)$，检查生成视频末态的方向是否**与 prompt 控制方向一致**——[[APEO 评测框架|APEO]] 的 Outcome 维度专门捕捉这类失败。
4. **危害**: 一旦下游用这种视频作为机器人策略训练数据或仿真预测，会引入系统性的因果错误信号。
