# Qwen3-VL

## 定义

Qwen3-VL 是阿里巴巴通义千问团队发布的第三代视觉-语言大模型，支持高分辨率图像理解和精确的视觉定位，具备强大的名词短语提取和目标定位能力。

## 核心要点

1. **高分辨率视觉理解**: 支持动态分辨率，对细粒度视觉细节有强感知能力
2. **名词短语提取**: 从语言指令中准确提取对象名称，作为视觉定位的文本提示
3. **与 SAM 结合**: 提取的名词短语作为 SAM 3 的 text prompt，驱动精准实例分割
4. **在 OA-WAM 中的角色**: 仅用于提供语义标签（不进入主干网络），配合 SAM 3 完成对象发现

## 代表工作

- [[OA-WAM]]: 用 Qwen3-VL 提取名词短语 → 驱动 SAM 3 分割 → 构建槽地址 addr
