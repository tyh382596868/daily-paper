# Episodic Memory（片段记忆）

## 定义
在神经网络或 agent 中存储过去经历（observation-action 对或状态序列）的显式记忆机制，与隐式循环状态（RNN/Transformer KV-cache）相对。

## 核心要点
1. 显式存储历史片段，支持选择性检索
2. 在稀疏时序依赖任务中优于循环记忆
3. 与认知科学中海马体的情节记忆对应
