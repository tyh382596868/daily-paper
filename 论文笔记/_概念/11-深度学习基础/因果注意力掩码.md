# 因果注意力掩码

## 定义

因果注意力掩码（Causal Attention Mask）是自回归 Transformer 中用于限制信息流向的二值掩码：每个位置只能 attend 到自身及之前的位置，防止"看到未来"。

## 标准因果掩码

标准下三角掩码 $M_{ij} = \mathbb{1}[j \leq i]$，使得 attention 计算变为：

$$
\text{Attention}(Q, K, V) = \mathrm{softmax}\!\left(\frac{QK^\top}{\sqrt{d}} + \log M\right)V
$$

（$M_{ij} = 0$ 对应 $-\infty$ 屏蔽）

## 自回归视频中的扩展（TF 掩码）

在 [[Causal-rCM]] 的 Teacher-Forcing Packed Forward 中，将 clean context 帧和 noisy target 帧拼接后，需要更精细的掩码：

- **Clean 块**：双向或因果自注意力（可 attend 彼此）
- **Noisy 块**：只能 attend 到 clean 历史，不能互相 attend

这种 **TF 注意力掩码** $M_{\text{TF}}$ 不是标准下三角，而是块结构稀疏掩码，在 [[FlashAttention-2]] 中表示为 admissible query-key 区间（无需物化密集掩码）以节省显存。

## 超 token 级时序因果注意力（Cosmos 3）

在 [[Cosmos 3]] 的生成塔中，时序因果注意力在**视觉超 token 粒度**（每帧所有空间 latent token 为一个超 token）上施加因果掩码，而非单个 patch token 级别，更符合帧间时序因果性。
