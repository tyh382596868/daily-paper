# Embodied AI

## 定义

Embodied AI（具身智能）研究**具有物理体的智能系统**——机器人、自动驾驶车辆、AR/VR agent 等——如何从感知、动作与环境交互中学习智能行为。区别于纯文本 / 视觉理解模型，强调 **闭环 (perception → action → environment)** 与 **物理一致性**。

## 核心要点

1. **代表领域**: 操作（manipulation）、导航、locomotion、[[自动驾驶]]
2. **代表模型**:
   - [[VLA]] / [[OpenVLA]] / [[π₀]] / [[Pi05]]: 通用机器人策略
   - [[World Action Model]] / [[WAIM]]: 世界-动作联合建模
   - [[GR00T N1.7]]: 通用 humanoid 基础模型
3. **常见数据集**: [[DROID]], [[OXE]], [[LIBERO]], [[Ego4D]]
4. **核心挑战**: sim-to-real, 长程任务, 数据稀缺, safety
