# 统一因果分类法（Unified Causal Taxonomy）

## 定义

由 [[WhatIfWorld]] 提出的跨 embodiment 物理因果变量分类体系：把具身场景中可对结果产生因果影响的物理变量组织成两域、六类[[物理因果原语]]，使**自动驾驶**和**机器人操作**两个表面差异巨大的领域共用同一套评测维度。

## 核心要点

### 两域六原语

| 域 | 物理原语 | 自动驾驶实例 | 机器人操作实例 |
|---|----------|-------------|---------------|
| **D1 Environment** | Surface Properties | 干燥沥青 vs 泥泞/结冰道路 | 玻璃面 vs 橡胶垫 |
| | Material & Medium | 晴天 vs 雨/雪 | 木块（刚性） vs 海绵（可形变） |
| | Obstacle Configuration | 道路畅通 vs 静态障碍 | 工作区清空 vs 路径有遮挡 |
| **D2 Interaction** | Spatial Alignment | 横向变道偏移 | 夹爪闭合位置 |
| | Force/Degree | 轻刹 vs 猛踩油门 | 轻触 vs 重推 |
| | Temporal Sequencing | 加速时机 | 夹爪闭合时机 |

### 设计原则

1. **跨域共享**: 每个原语都同时在驾驶和操作两域找到对应实例，体现"物理规律的普适性"。
2. **D1 vs D2**: D1 描述**环境如何**（静态外因），D2 描述**交互如何**（动作-环境耦合）。
3. **正交性**: 6 个原语彼此可单独改变，不构成 trivial 子集关系。
