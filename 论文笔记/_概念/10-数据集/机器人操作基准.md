# 机器人操作基准（Robot Manipulation Benchmark）

## 定义

用于系统评测机器人操作策略（如抓取、放置、推送等）性能的标准化评测平台，通常提供仿真环境、标准任务集、性能指标和基线模型。

## 核心要点

**主流仿真操作基准**：

| 基准 | 特点 |
|------|------|
| [[RLBench]] | 100+ 任务，基于 CoppeliaSim |
| CALVIN | 长时程语言条件操作 |
| ManiSkill2 | GPU 并行化，大规模评测 |
| [[RoboTwin]] | 双臂、多形态，支持安全评测 |
| SimplerEnv | 真实到仿真迁移评测 |
| LIBERO | 知识迁移，5 套任务 |

**评测维度**：任务成功率、泛化性、样本效率、安全性（新兴）

**局限性**：
1. 多数仅用成功率衡量，忽视安全过程
2. [[ForesightSafety-VLA]] 指出需要过程级安全指标补充

## 代表工作

- [[ForesightSafety-VLA]]: 在 RoboTwin 上建立安全增强的操作基准
