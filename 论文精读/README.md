# 论文精读

教学式深度精读笔记，每篇论文一个扁平文件：`论文精读/<方法名>.md`。

## 怎么用

给我一篇论文（arXiv 链接 / PDF 路径 / 标题），说一句：

- `精读 <论文>`
- `讲透这篇论文 <链接>`
- `帮我吃透 <方法名>`

我会用 `paper-deep-dive` skill 把它讲透：前置知识、问题动机、核心思想（直觉/类比）、
方法逐层拆解、关键公式逐步推导、图表精读、实验解读、复现思路、批判延伸、常见疑问 Q&A。

## 与「论文笔记」的区别

| | 触发 | 产出 | 存放 |
|---|---|---|---|
| **论文笔记**（paper-reader） | `读一下 XXX` | 结构化归档速记 | `论文笔记/分类/` |
| **论文精读**（paper-deep-dive） | `精读 XXX` | 教学式深度讲解（更长） | `论文精读/` |

两者互不覆盖，可对同一篇论文并存。
