### 1. HY-World 2.0: A Multi-Modal World Model for Reconstructing, Generating, and Simulating 3D Worlds
- **作者**: Tencent Hunyuan Team
- **机构**: Tencent Hunyuan
- **链接**: [arXiv](https://arxiv.org/abs/2604.14268) | [PDF](https://arxiv.org/pdf/2604.14268)
- **来源**: 🔥 HF Trending，⬆️ 119

![](https://arxiv.org/html/2604.14268v1/pics/teaser0.jpeg)

- **核心方法**: 多模态 3D 世界模型框架，接受文本/单图/多视图/视频四种输入，输出可导航的 3D 高斯泼溅（[[3D Gaussian Splatting]]）场景。生成路径是 4 阶段 pipeline：① 全景生成（Panorama Generation）初始化世界 → ② 轨迹规划（Trajectory Planning）推 exploration camera path → ③ Worldstereo 多视图扩展观测 → ④ WorldNav 收敛成可导航 3DGS。重建路径（多视图/视频输入）用 [[WorldMirror]] 模块走前馈式 3D 重建。整套架构 DiT 骨架 + RoPE 位置编码。
- **对比方法/Baselines**: WorldMirror、WorldStereo、WorldNav 是同家族的子模块；外部 baselines 包括之前的开放世界生成方法（Marble、[[CtrlWorld]] 等）。
- **借鉴意义**: 这是少数把"生成 + 重建 + 模拟"统一在一个 frame 下的工业级世界模型，4 阶段 pipeline 对做 [[ManiSkill]]/[[RoboCasa]] 这类仿真环境构造的人是很直接的范式参考。3DGS 作为世界模型表征会进一步强化。
- **锐评**: 腾讯出品，工程量肉眼可见，但 paper 写法是典型的"我们做了 4 件事，每件都跟前作差一点点"。"高保真可导航"这种 claim 缺定量物理一致性指标——只比视觉 metric 没意思。真正有意思的是 WorldNav 这一阶段如果能拿到物理可交互能力，会是 [[WorldAct]] 那条线的工业级答案。但 paper 里这部分基本一笔带过。技术报告调调，看 demo 比看 paper 收获大。🔥
- **关联笔记**: [[3D Gaussian Splatting]]、[[世界模型]]、[[WorldAct]]、[[Controllable 世界模型]]、[[CtrlWorld]]、[[8-仿真器]]

### 2. WorldArena 2.0: Extending Embodied World Model Benchmarking on Modality, Functionality and Evaluation
- **作者**: Yu Shang 等
- **机构**: Tsinghua、SJTU、Princeton、CAS、Stanford、HKU、NUS 等多机构联合
- **链接**: [arXiv](https://arxiv.org/abs/2605.17912) | [PDF](https://arxiv.org/pdf/2605.17912)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2605.17912v1/x1.png)

- **核心方法**: 把 embodied world model benchmark 从"纯视觉预测 + 离线评估 + 仿真器内"三个限制里同时拉出来。扩展三件事：① modality——加入触觉、力、proprioception 等非视觉信号；② functionality——除了 prediction 还评估 control / planning；③ evaluation——把闭环 RL 评估接进来，对接 [[RoboTwin]]、[[LIBERO]] 等真实/仿真平台。覆盖 [[Cosmos-Predict]]、[[CtrlWorld]] 等当前 SOTA 世界模型，给出全维度排行。
- **对比方法/Baselines**: 前作 WorldArena 1.0、[[VBench]]、其他视觉预测 benchmark。
- **借鉴意义**: 如果你做世界模型，这是 2026 年最系统的一份 evaluation reference——modality/functionality/evaluation 三轴比 [[VBench]] 那种只看视觉质量的强太多。可以直接用它的 protocol 来 ablate 自己的 world model。
- **锐评**: benchmark paper 写得好坏的分水岭是"会不会有人用"。WorldArena 2.0 的三轴扩展方向是对的（多模态 + 功能性 + 闭环），但跑 RoboTwin / LIBERO 这套真实/仿真混合 evaluation 的算力门槛不低，开源版能不能压到单卡 H100 跑得动是关键。看 GitHub 再说。🔥
- **关联笔记**: [[世界模型]]、[[RoboTwin]]、[[LIBERO]]、[[Cosmos-Policy]]、[[CtrlWorld]]、[[VBench]]
- 💡 **想精读？** 运行：`读一下 WorldArena 2.0`

### 3. PH-Dreamer: A Physics-Driven World Model via Port-Hamiltonian Generative Dynamics
- **作者**: Xueyu Luan, Chenwei Shi
- **机构**: Shanghai Research Institute for Intelligent Autonomous Systems、同济大学
- **链接**: [arXiv](https://arxiv.org/abs/2605.18303) | [PDF](https://arxiv.org/pdf/2605.18303)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2605.18303v1/assets/fig1a.png)

- **核心方法**: 把 [[DreamerV3]] / RSSM 这条线的潜在世界模型加上 Port-Hamiltonian 结构约束。三个改动：① 隐式物理 prior——把潜变量演化建模为 action-controlled 能量路由（含 flow 和 dissipation），保证 conservation/dissipative 原则；② structural-aware actor-critic 训练，让策略尊重物理约束；③ 在 [[MuJoCo]] 控制 benchmark 上对比 [[DreamerPro]] / DreamerV3。
- **对比方法/Baselines**: [[DreamerV3]]、DreamerPro、[[RSSM]] 系列。
- **借鉴意义**: 这是少数把"硬物理结构"塞进神经潜在动力学的尝试，对做 [[基于模型的强化学习]] / model-based RL 的人有方法学价值——Port-Hamiltonian 这个 framework 在系统辨识/控制领域很标准但在 deep RL 里很少见。
- **锐评**: 数学很漂亮，但 paper 写法走的还是 Dreamer 那一套"换骨架不换底子"——MuJoCo 上涨几个点不能 close the loop 到机器人控制。"潜变量演化遵守能量守恒"这件事 ablate 起来很微妙——是真的物理 grounded，还是只是又一个 inductive bias 让 overfit 变难？看完整篇才能判断。但作为"physical structure 入 world model"的方法学参考，必读。🔥
- **关联笔记**: [[DreamerV3]]、[[基于模型的强化学习]]、[[MuJoCo]]、[[世界模型]]
- 💡 **想精读？** 运行：`读一下 PH-Dreamer`

### 4. Incantation: Natural Language as the Action Interface for Multi-Entity Video World Models
- **作者**: Shangwen Zhu 等
- **机构**: SJTU、NVIDIA Research、USTC、UCAS、NUS、UWaterloo、HKUST、HKU、ZGCA
- **链接**: [arXiv](https://arxiv.org/abs/2605.18601) | [PDF](https://arxiv.org/pdf/2605.18601)
- **来源**: 📰 HF Daily，⬆️ 1

![](https://arxiv.org/html/2605.18601v1/x2.png)

- **核心方法**: 现有交互式视频世界模型只能控制一个实体（玩家），多实体控制靠 animation ID/device input 这种 design-time 硬编码接口。Incantation 把控制接口换成自然语言："Action-Index"把语言指令解码成动作 token，跨实体可用、跨世界可迁移。DiT + RoPE backbone + VLM 解析语言指令。
- **对比方法/Baselines**: GameNGen、DIAMOND、Oasis、Matrix-Game、Mineworld 等单实体视频世界模型。
- **借鉴意义**: 多实体控制对 embodied multi-agent 系统的世界模型是核心痛点——MIneworld 之类的能控自己但管不了 NPC 和环境其他智能体。Incantation 的"NL 即接口"思路如果真的可迁移，对做 [[ReactiveGWM]] / [[CtrlWorld]] 这条线的人是直接借鉴。
- **锐评**: "自然语言作为通用 action interface"听着很 elegant 但实操有大坑：① 语言指令的语义粒度跟连续控制的频率不匹配；② "跨世界"的 claim 通常被表演空间约束打脸。摘要里说"unlock expressiveness that no prior interface can achieve"——空话，数字呢？等看 FVD/ACA 这些数字才能判断。👀
- **关联笔记**: [[世界模型]]、[[ReactiveGWM]]、[[Controllable 世界模型]]、[[Vid2World]]

### 6. AffordVLA: Injecting Affordance Representations into Vision-Language-Action Models via Implicit Distillation
- **作者**: Weijie Kong 等
- **机构**: 浙江大学 Grasp Lab、Torch Kernel Co.
- **链接**: [arXiv](https://arxiv.org/abs/2605.17517) | [PDF](https://arxiv.org/pdf/2605.17517)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2605.17517v1/x1.png)

- **核心方法**: 现有 affordance 方法靠 mask injection / external perception module，需要额外标注。AffordVLA 用**隐式蒸馏**把 affordance 知识注入 VLA 视觉表征——不显式给 mask，让模型自己学会 attend 到任务相关的功能性区域。在 [[RoboTwin2]] 上评估，对比常规 [[VLM]]-based VLA。
- **对比方法/Baselines**: 显式 affordance mask 注入的 VLA（如 [[3DFlowAction]]、[[Gen2Act]]）、纯 VLM-VLA。
- **借鉴意义**: 把 affordance 从"显式 supervision"做成"implicit representation distillation"，是 VLA 视觉编码器优化的清爽思路。可直接迁到 [[OpenVLA]] / [[π₀]] 这种主流 backbone 上。
- **锐评**: "隐式蒸馏"在 VLA 里听着新但本质是表征学习 + KLD——能不能稳定收敛、是不是只在 RoboTwin2 这种结构化场景吃得住，要看 ablation。"避免额外标注"的卖点对工业落地 attractive，但 paper 没说蒸馏的 teacher 是谁——teacher 不要标注的话，先决条件就破了。👀
- **关联笔记**: [[VLA]]、[[OpenVLA]]、[[3DFlowAction]]、[[Gen2Act]]、[[RoboTwin]]
- 💡 **想精读？** 运行：`读一下 AffordVLA`

### 7. DyGRO-VLA: Cross-Task Scaling of Vision-Language-Action Models via Dynamic Grouped Residual Optimization
- **作者**: Sixu Lin, Yunpeng Qing, Litao Liu 等
- **机构**: 未署明（疑似港中文+腾讯系）
- **链接**: [arXiv](https://arxiv.org/abs/2605.17486) | [PDF](https://arxiv.org/pdf/2605.17486)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2605.17486v1/figures/rft.png)

- **核心方法**: 现有 VLA RL 优化器 task-specific，多任务训练时梯度相互干扰。DyGRO-VLA 提出"动态分组 residual"——按任务相似度动态分组，每组算 residual reward，避免梯度冲突。在 [[LIBERO]] + [[RoboTwin2]] 上做多任务 scaling 测试。
- **对比方法/Baselines**: 任务级 reweighting / 样本级 reweighting 的多任务 baseline；GRPO 直接多任务。
- **借鉴意义**: 跟 [[Flash-GRPO]] / [[PCM]] 一起，是当前 VLA RL "效率与稳定"三人转里的一员。如果你做大规模多任务 VLA fine-tune，得知道这条 dynamic grouping 路线。
- **锐评**: "dynamic grouping"听着像聚类 + RL 的拼接，但 paper 没在摘要里说怎么稳定地分组——分组本身需要 reward signal 还是 task encoding？这个细节决定全篇成立与否。多任务 VLA 是真实需求，但每家都说自己的方法能 scale，最后能不能 scale 到 100+ 任务才算数。⚠️
- **关联笔记**: [[VLA]]、[[GRPO]]、[[LIBERO]]、[[CM-GRPO]]、[[WMPO]]

### 8. StableVLA: Towards Robust Vision-Language-Action Models without Extra Data
- **作者**: Yiyang Fu 等
- **机构**: 南大、南开、北大、清华
- **链接**: [arXiv](https://arxiv.org/abs/2605.18287) | [PDF](https://arxiv.org/pdf/2605.18287)
- **来源**: 📰 HF Daily，⬆️ 11

![](https://arxiv.org/html/2605.18287v1/x1.png)

- **核心方法**: 系统量化 SOTA VLA 在未见视觉扰动下的性能崩塌（光照变化、相机角度、纹理替换），然后**不加任何额外数据**通过纯训练侧 trick（疑似 information bottleneck IB + OFT 微调策略）拉回鲁棒性。在 [[LIBERO]]、[[CALVIN]]、[[OpenVLA]] 上验证。
- **对比方法/Baselines**: [[OpenVLA]]、其他 robustness 方法（如 [[DBLP]]）需要额外数据增强或 domain randomization。
- **借鉴意义**: 现实落地里"不加数据做鲁棒"比"加数据"金贵——数据采集本来就是 VLA 卡点。这条线（IB + OFT）值得每个做 VLA 落地的人对照参考。
- **锐评**: "without extra data"是 PR 卖点——99% 的 robustness 方法都不靠纯堆数据，关键是 trick 怎么设计、对哪些扰动 work。paper 没把 fail case 写在摘要里，意味着扰动谱可能挑过。但作为 VLA 鲁棒性的低成本 baseline 值得记。👀
- **关联笔记**: [[VLA]]、[[OpenVLA]]、[[LIBERO]]、[[CALVIN]]
- 💡 **想精读？** 运行：`读一下 StableVLA`

### 9. COAST: Contrastive Conceptor Activation Steering — Unlocking Vision-Language-Action Models
- **作者**: Miranda Muqing Miao 等
- **机构**: University of Pennsylvania
- **链接**: [arXiv](https://arxiv.org/abs/2605.17144) | [PDF](https://arxiv.org/pdf/2605.17144)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2605.17144v1/x1.png)

- **核心方法**: VLA 推理时 steering——用"conceptor"（一个把数据软投影到目标分布主成分的线性算子）识别"成功关键"的子空间，对比性地激活引导 frozen VLA policy。无需重训。在 [[MetaWorld]]、[[LIBERO]]、[[RoboCasa]] 上验证。
- **对比方法/Baselines**: [[CAA]]（Contrastive Activation Addition）、reward-guided steering、VLM-based planning verification。
- **借鉴意义**: 把 LLM 圈的 activation steering 工具迁过来，是"不重训、提升 VLA 鲁棒性"这条路线的清爽方案。如果你的 VLA 已经 frozen 部署，COAST 是少数可推理时调的工具。
- **锐评**: conceptor 这套数学（Jaeger 2014）其实老了，但在 VLA 上应用是新的。问题是"identify success-critical subspaces"需要 paired 成功/失败样本——这个数据从哪来？摘要没说。如果还得标 success/failure 样本，那"frozen, no retraining"就只是部分成立。👀
- **关联笔记**: [[VLA]]、[[MetaWorld]]、[[LIBERO]]、[[RoboCasa]]
- 💡 **想精读？** 运行：`读一下 COAST`

### 10. SADP: Subgoal-Aware Diffusion Policy for Explainable Robots Learned from Foundation Model Annotations
- **作者**: Site Hu 等
- **机构**: 大阪大学
- **链接**: [arXiv](https://arxiv.org/abs/2605.16871) | [PDF](https://arxiv.org/pdf/2605.16871)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2605.16871v1/x1.png)

- **核心方法**: 给 [[Diffusion Policy]] 加 subgoal 结构——用基础模型自动从 demo 里抽取 subgoal 标注，policy 在生成动作的同时输出当前 subgoal 进度（"我现在做到第几步"），让机器人执行可解释。在 SpongeInPlate / ItemInDrawer 等任务上验证。
- **对比方法/Baselines**: 原版 Diffusion Policy、[[HRL]] baseline、[[TARAD]]。
- **借鉴意义**: explainable robot 是落地必须项（事故归因、用户信任），SADP 的"subgoal 进度作为可观察的副输出"是低侵入式实现方式。比硬接 LLM 解释器优雅得多。
- **锐评**: foundation model 自动标 subgoal 这件事，质量随任务复杂度急剧衰减——长程任务 LLM 给的 subgoal 经常和实际执行脱节。"explainable"的 claim 还要看用户怎么消费这些 subgoal label，paper 只演示了能输出，没说有没有提升下游 task success。⚠️
- **关联笔记**: [[Diffusion Policy]]、[[HiF-VLA]]、[[CoT-VLA]]

### 11. Health-Conditioned VLA Models for Malfunction-Aware Robot Control
- **作者**: Hüseyin Arslan, Özgür Erkent
- **机构**: 未署明
- **链接**: [arXiv](https://arxiv.org/abs/2605.16056) | [PDF](https://arxiv.org/pdf/2605.16056)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2605.16056v1/healthvla_arch.png)

- **核心方法**: VLA 通常假设机器人物理完好。这篇加一个 "health vector"作为输入——记录关节退化、执行器失效、夹爪弱化等物理故障状态——让 VLA 在已知机器人健康状态下适应控制策略。基于 [[OpenVLA]] 改造，在 [[LIBERO]] 上验证。
- **对比方法/Baselines**: 原版 OpenVLA、其他 fault-tolerant 控制方法（多基于 MPC）。
- **借鉴意义**: 机器人长期运行的物理退化是工业落地真实问题（伺服磨损、传感器漂移）。把"健康状态"显式编码进 VLA 是直观且 underexplored 的方向。

### 12. PCM: Probabilistic Chunk Masking for Efficient VLA RL

## 今日趋势判断

VLA 进入"精修阶段"——主流方法（OpenVLA / pi0 / Diffusion Policy）骨架稳定后，研究开始往**鲁棒性、可解释、安全性、训练效率**这些工程维度细化。今天一口气出现 StableVLA / Health-VLA / COAST / SADP / CoC-Faithfulness / Typographic-Attacks 这类"加帽子"工作，说明赛道在收敛、应用在抬头。世界模型这边腾讯下场（HY-World 2.0）+ PH-Dreamer 的物理结构尝试，是"产业化"和"基础数学"两端同时发力。值得做的事：把 PH-Dreamer / WorldArena 2.0 的方法搬到自己的世界模型里 ablate 一次。
