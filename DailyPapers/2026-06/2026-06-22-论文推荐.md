### 1. Reward as An Agent for Embodied World Models (SAGE)
- **作者**: 未提取
- **机构**: 未知
- **链接**: [arXiv](https://arxiv.org/abs/2606.19990) | [PDF](https://arxiv.org/pdf/2606.19990)
- **来源**: 📄 arXiv 关键词检索
- 📒 **笔记**: [RewardAgent](../论文笔记/1-生成模型/RewardAgent.md)

![](https://arxiv.org/html/2606.19990v1/x1.png)

- **核心方法**: SAGE 把 reward model 从静态打分器改造为主动探索智能体。现有 RL 微调世界模型的方案依赖保守 rollout（近分布采样），SAGE 的 reward agent 用 [[GRPO]] 优化自身策略，主动提出"高信息量"的 rollout 请求，迫使 [[DynDiff]] 世界模型走出训练分布边界。通过 [[CFG]] 控制动态强度，实现 dynamic-aware 探索。在 [[AgiBotWorld]] 双臂数据集上验证，benchmark 为 TaskEval。
- **对比方法/Baselines**: 基础模型 [[DynDiff]]（其本身的世界模型）；借鉴了 [[UnifiedReward]] 做视频对齐；在 [[AgiBotWorld]] 上对比标准保守 rollout 方案
- **借鉴意义**: 对做机器人世界模型 RL 微调的人直接有用——把 reward model 当 agent 主动生成 curriculum 的思路可迁移到任何 action-conditioned video generation 训练框架，尤其是数据稀缺场景
- **锐评**: 核心 idea 很聪明：reward agent 既评分又主动探索，打破了"生成 → 评分 → 微调"的被动循环。但摘要没说清 SAGE agent 本身如何训练——reward signal 从何来？如果仍依赖人工标注，那只是套了一层壳。仅在 AgiBotWorld 单数据集验证，泛化性存疑。方法有意思，细节需看全文确认。 🔥

### 4. Through the PRISM: Preference Representation in Intermediate States of Video Diffusion Models

- **机构**: City University of Hong Kong, Columbia University, CUHK
- **链接**: [arXiv](https://arxiv.org/abs/2606.20310) | [PDF](https://arxiv.org/pdf/2606.20310)

- **核心方法**: PRISM 发现视频扩散模型在去噪过程的中间时间步（noisy intermediate states）已包含足够的偏好判别信息，无需解码到 clean 像素即可做视频质量评分。在 [[CogVideoX]] 的中间激活上接一个轻量级判别头，避免 VAE 解码的计算开销。推理时可在 [[BoN]]（Best-of-N）搜索中用中间态剪枝低质量候选，节省整体推理成本。

- **借鉴意义**: 对做 video generation + RLHF 或 inference-time scaling 的人有价值：不完整生成就能评分，大幅加速 BoN 或 reward-guided generation
- **锐评**: 核心发现很 elegant——扩散中间态更接近 representation space，用它做判别在理论上站得住。但有两个疑问：不同时间步的判别能力差异有多大？选哪个步是新的超参数。其次，方法依赖 CogVideoX 的特定架构，泛化到 HunyuanVideo、Wan 等是否需要重训？ 👀

### 7. Frequency-Aware Flow Matching for Continuous and Consistent Robotic Action Generation (FAFM)
- **作者**: 未提取
- **机构**: 未知
- **链接**: [arXiv](https://arxiv.org/abs/2606.20135) | [PDF](https://arxiv.org/pdf/2606.20135)
- **来源**: 📄 arXiv 关键词检索
- 📒 **笔记**: [FAFM](../论文笔记/3-Robotics/VLA/FAFM.md)

![](https://arxiv.org/html/2606.20135v1/figure/intro_v4.png)

- **核心方法**: FAFM 针对 action chunking 的两个问题——chunk 边界不连续和高频抖动——将动作序列用 [[DCT]]（离散余弦变换）投影到频域，flow matching 在频域空间内操作。低频分量对应整体轨迹平滑度，高频分量对应精细调整，FreqPolicy 加权损失对不同频率施加不同约束。在 [[LIBERO]]、LapGym 和真实机器人上验证（`has_real_world=True`）。
- **对比方法/Baselines**: 对比 [[DP]]（Diffusion Policy）及标准 flow matching；借鉴 [[FreqPolicy]] 的频域先验；在 [[LIBERO]] 和 LapGym 做消融
- **借鉴意义**: 直接有用。如果你在用 diffusion/flow policy 做 manipulation 并遇到 chunk 边界抖动问题，这篇值得精读
- **锐评**: DCT 表示本身就是正交分解，不同频率对应不同运动特征，用频域加权损失是合理的归纳偏置——idea elegant。真实机器人实验有说服力。唯一疑问：频域 flow matching 的推理速度如何？DCT/IDCT 的额外计算开销在实时控制场景下的延迟需要报出来。 🔥
- 💡 **想精读？** 运行：`读一下 Frequency-Aware Flow Matching for Continuous and Consistent Robotic Action Generation`

### 8. Start Right, Arrive Right: Asynchronous Execution via Initial Noise Selection (PAINT)
- **作者**: 未提取
- **机构**: VinRobotics, VinUniversity, DFKI, University of Stuttgart, IMPRS-IS
- **链接**: [arXiv](https://arxiv.org/abs/2606.19774) | [PDF](https://arxiv.org/pdf/2606.19774)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2606.19774v1/x1.png)

- **核心方法**: PAINT（Prefix-Anchored Initial Noise Transport）通过选择初始噪声保证异步执行下 action chunk 的连续性。生成下一个 chunk 时，用 OT（最优输运）找一个初始噪声，使 flow matching 生成的新 chunk 前几帧与当前执行 chunk 末几帧平滑衔接。用 [[TensorRT]] 加速，在真实机器人上测试延迟改善效果（`has_real_world=True`）。
- **对比方法/Baselines**: 对比 Slide-Naive（朴素滑窗）等异步执行策略；用 OT 做噪声初始化
- **借鉴意义**: 对做 real-time deployment 的 flow policy 或 diffusion policy 是直接可用的工程技巧。chunk 边界连续性是落地必须面对的问题
- **锐评**: 问题定义很实际——flow policy 推理慢，机器人不能等。OT 选初始噪声比直接 padding 或插值有更强的理论依据。但 OT 求解本身有计算开销，[[TensorRT]] 加速的延迟数字需要看全文。方法依赖 flow matching 架构，不能直接迁移到 diffusion policy。 👀
- 💡 **想精读？** 运行：`读一下 Start Right, Arrive Right: Asynchronous Execution via Initial Noise Selection`

### 3. Mem-World: Memory-Augmented Action-Conditioned World Models for Persistent Robot Manipulation
- **作者**: Zirui Zheng 等
- **机构**: 大连理工大学 + Samsung R&D（北京）
- **链接**: [arXiv](http://arxiv.org/abs/2606.18960v2) | [PDF](https://arxiv.org/pdf/2606.18960v2)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2606.18960v2/figs/pipeline.png)

- **核心方法**: 解决 action-conditioned WM 在长期操作中的状态持久性问题。方法：在 video prediction 基础上加 **Surfel-based 3D 记忆**——InitSurfels 初始化场景点云，UpdateSurfels（用 wrist pose + 深度）持续更新，NMS 去重。推理时 TopK 检索历史 surfel 注入生成上下文，使遮挡物体的状态得以持续追踪。输入：RGB + depth + action；输出：一致性视频预测。Ctrl-World 是同团队的无记忆 baseline。

- **借鉴意义**: Surfel 记忆 + action-conditioned WM 的组合对做多步操作规划（尤其涉及遮挡）的人直接有用，代码已开源（GitHub）。
- **锐评**: 大连 + Samsung 的组合不是顶 tier，但思路扎实，3D surfel 记忆比纯 token 记忆（如今天的 MemoryWAM）在几何精度上有优势。主要风险点：UpdateSurfels 的实时计算开销，以及在高动态场景（多物体同时运动）下 NMS 去重 + TopK 检索的精度损失。Surfel 参数估计对深度传感器噪声的鲁棒性也需要验证。 🔥

- **核心方法**: 将 WAM 中的视频生成替换为单帧图像编辑（用 [[OmniGen2]] / [[FLUX]] 作为 image editor），只预测下一帧而非整个视频序列，再用该帧 + 下一 action 继续 rollout。规避了视频 WAM 的三个代价：dense multi-frame token、时间一致性约束高、训练计算爆炸。有真实机器人实验（`has_real_world=True`），在 [[LIBERO]]、[[RoboTwin]]、[[RoboTwin2]] 上验证。

### 11. Finetuning Vision-Language-Action Models Requires Fewer Layers Than You Think
- **作者**: Gia-Binh Nguyen 等
- **机构**: VinRobotics + VinUniversity + DFKI + Stuttgart + KAIST + 多个欧洲机构（11 家联合）
- **链接**: [arXiv](http://arxiv.org/abs/2606.20246v1) | [PDF](https://arxiv.org/pdf/2606.20246v1)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2606.20246v1/images/CLS_Pruning_v2.png)

- **核心方法**: 用 [[CKA]]（Centered Kernel Alignment）分析 VLA 微调前后各层的表示变化，发现大多数层在微调中几乎不动，需要更新的层集中在靠近 action head 的后段。基于此提出 CLP（Coarse Layer Pruning）：只微调后 K 层（K ≪ 总层数），其余冻结。在 [[OpenVLA]]、[[SmolVLA]]、[[CogACT]] 等模型上，[[LIBERO]]、[[SimplerEnv]]、[[ALOHA]]、[[RoboCasa]] 四个 benchmark 均有验证，有真实机器人实验（`has_real_world=True`）。
- **对比方法/Baselines**: 对比全参数微调、[[LoRA]]、[[MoLe]]（Mixture of Layers）、[[SpecPrune]] 等参数高效微调方法。
- **借鉴意义**: 直接实用——如果在微调 VLA，试试只调最后几层，能省不少计算。VinRobotics 今天刷了两篇（EquiVLA 也是），团队产出率高。
- **锐评**: CKA 分析工具本身不是新的，但用来系统分析 VLA 层重要性是个有价值的 empirical study。结论"只需调后 K 层"听起来反直觉但可能成立，因为 action 输出是局部的，早期层的语言视觉理解不需要变。但通用性是最大问题：不同任务（LIBERO vs ALOHA）的"需要调的层"是否一致？如果因任务而异，CLP 就需要 per-task 搜索 K，收益打折。 👀
- 💡 **想精读？** 运行：`读一下 Finetuning Vision-Language-Action Models Requires Fewer Layers Than You Think`

- **锐评**: Samsung + 东华的组合在技术深度上有限。"显式协调 > 隐式协调"这个 claim 其实已经被 [[ACT]] 的 joint state space 和 [[ALOHA]] 的设计暗示过了。SAE 没有说清楚比 joint action space 的优势在哪。感觉是工程集成 + 系统论文，novelty 偏低。真机实验是唯一加分项。 🫠

### 16. Tri-Info: Generalizable, Interpretable Failure Prediction for VLA Models via Information Theory
- **作者**: Yang Jinghan 等
- **机构**: 香港大学 InfoBodied AI Lab
- **链接**: [arXiv](http://arxiv.org/abs/2606.19998v1) | [PDF](https://arxiv.org/pdf/2606.19998v1)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2606.19998v1/x1.png)

- **核心方法**: VLA 失败预测模块（不修改 VLA 本身）。用互信息（MI）估计 action token 和 visual evidence token 的相关性：MI 低意味着动作和观测解耦，是失败的前兆信号。不需要修改 VLA，只是外挂检测器。与 [[FIPER]]、[[SAFE]]、STAC 的区别：基于特征距离的方法不如 MI 有可解释性，Tri-Info 能指出"哪部分视觉证据和动作脱节"。在 [[ALOHA]]、[[CALVIN]]、[[LIBERO]] 上测试，有真实机器人实验（`has_real_world=True`）。
- **对比方法/Baselines**: 对比 [[FIPER]]、[[SAFE]]、STAC、KNN-based 检测器，[[UniVLA]] 也在对比集。
- **借鉴意义**: 部署 VLA 到真实机器人时，Tri-Info 可作为安全监控模块——MI 低于阈值时暂停动作并请求人工干预。
- **锐评**: HKU 出品，信息论角度有新意，可解释性是真实需求。关键问题：预测时机——失败前多少帧能检测到 MI 下降？如果只在失败帧才检测到，那是事后确认而非预防。MI 估计的 online 计算开销（是否适合实时推理）也需要量化。两个关键数字：lead time 和 latency。 👀
- 💡 **想精读？** 运行：`读一下 Tri-Info: Generalizable, Interpretable Failure Prediction for VLA Models via Information Theory`

### 17. Invertible Neural Network Adapter for One-Step Flow Matching in Robot Manipulation
- **作者**: Zhang Yu, Ji Kangyi 等
- **机构**: 未知（富化未提取到机构信息）
- **链接**: [arXiv](http://arxiv.org/abs/2606.19194v1) | [PDF](https://arxiv.org/pdf/2606.19194v1)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2606.19194v1/x1.png)

- **核心方法**: 标准 flow matching 需多步 ODE 求解（推理慢），蒸馏到一步损失质量。ManiFlow 用可逆神经网络（INN）作为 adapter：INN forward pass = 一步采样，INN backward pass = 逆映射回训练分布，用可逆性做一致性约束训练一步蒸馏。输入：RGB + 语言 + [[QwenVL]] 特征；输出：连续动作序列。在 [[RoboTwin]] + 真实 UR 机器人上测试（`has_real_world=True`）。
- **对比方法/Baselines**: 对比标准 flow matching + 多步推理，[[OpenArm]] 平台上真机对比。
- **借鉴意义**: 如果在用 flow matching policy 且推理速度是瓶颈，INN adapter 的一步蒸馏方案值得尝试。
- **锐评**: 一步 flow matching 是当下热点（[[DMD]]、[[Consistency Models]] 都在解决这个问题），INN 的可逆性做一致性约束是个聪明角度。机构不明、只在 RoboTwin + 单款 UR 机器人上验证，泛化性未知。还需要看具体推理加速比和成功率 trade-off。 👀
- 💡 **想精读？** 运行：`读一下 Invertible Neural Network Adapter for One-Step Flow Matching in Robot Manipulation`

### 18. TactSpace: Learning a Physics-enriched Shared Latent Space for Tactile Sim-to-Real Transfer
- **作者**: Arunim Joarder, Arjun Bhardwaj, René Zurbrügg 等
- **机构**: ETH Zürich Robotic Systems Lab + Micro/Nanosystems Lab + ETH AI Center + NVIDIA
- **链接**: [arXiv](http://arxiv.org/abs/2606.18959v1) | [PDF](https://arxiv.org/pdf/2606.18959v1)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2606.18959v1/x1.png)

- **核心方法**: GelSight 触觉传感器的 sim-to-real gap 问题。用 ABAQUS [[FEM]] 物理仿真建模触觉变形（接触力 → deformation map），通过 [[InfoNCE]] contrastive loss 训练 [[ViTacFormer]]，使仿真 tactile map 和真实 GelSight image 在 latent space 中对齐。输入：sim tactile map + real GelSight image；输出：对齐后 latent vector，用于下游 grasp 成功预测。
- **对比方法/Baselines**: 对比 [[ViTacFormer]] baseline 和其他 sim-to-real tactile 方法；下游任务 grasp 成功预测评估。
- **借鉴意义**: 如果在用触觉传感器做精细操作，ETH + NVIDIA 的这套 FEM + InfoNCE pipeline 是当前 SOTA 水平的触觉 sim-to-real 方案，FEM 物理建模是可信的 ground truth 来源。
- **锐评**: ETH + NVIDIA 保障工程质量，ABAQUS FEM 做 ground truth 是物理准确的选择。但 `has_real_world=False` 是减分——最终验证是 sim-sim 对比，没有真实机器人抓取实验。真实 GelSight 的噪声与 ABAQUS 仿真的差异在实际部署中有多大，还缺数据。对新材料是否需要重跑 FEM 仿真（代价高）？ 👀
- 💡 **想精读？** 运行：`读一下 TactSpace: Learning a Physics-enriched Shared Latent Space for Tactile Sim-to-Real Transfer`

### 19. Do as I Do: Dexterous Manipulation Data from Everyday Human Videos
- **作者**: Bhawna Paliwal 等
- **机构**: UC Berkeley
- **链接**: [arXiv](http://arxiv.org/abs/2606.19333v1) | [PDF](https://arxiv.org/pdf/2606.19333v1)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2606.19333v1/figures/title.jpg)

- **核心方法**: 从 YouTube / 互联网人类操作视频中自动生成灵巧手操作轨迹。Pipeline：（1）[[HaWoR]] 提取手部 MANO 参数；（2）[[MoGe]] 重建 3D 场景 + [[FoundationPose]] 跟踪物体 6DoF；（3）手部轨迹 retarget 到机器人灵巧手（运动学优化 + [[MuJoCo]] simulation）；（4）生成轨迹用于 IL 训练。有真实灵巧手抓取实验（`has_real_world=True`）。
- **对比方法/Baselines**: 对比 [[H2Sim2Robot]]、[[VideoManip]] 等人类视频 → 机器人数据方法，用 [[OakInk2]] + [[DexYCB]] 验证数据质量，ACT/IL 做下游评测。
- **借鉴意义**: 如果在训练灵巧手策略且数据稀缺，这套从互联网视频自动生成轨迹的 pipeline 是个实用的 data flywheel，UC Berkeley 背书可信度高。
- **锐评**: Berkeley 出品，有真机验证。但依赖链条长（HaWoR → MoGe → FoundationPose → retargeting），每一步都引入误差。关键指标：retargeting 成功率多少？不同灵巧手形态（DexHand vs Shadow vs Allegro）之间迁移如何？互联网视频的抓取多样性和质量能否保证？这些是决定 pipeline 实用价值的关键数字。 👀
- 💡 **想精读？** 运行：`读一下 Do as I Do: Dexterous Manipulation Data from Everyday Human Videos`
