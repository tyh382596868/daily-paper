![](https://arxiv.org/html/2606.16993v1/figures/dreamx-world_teaser_fig.jpg)

- **核心方法**: 通用交互式世界模型，输入文本/图像，输出长程可控视频流。架构基于 [[DiT]] + [[ParaVAE]]（并行 VAE 提速编解码），支持三类控制：（1）相机导航——探索新区域；（2）区域重访——维护历史 Memory-Conditioned 缓冲区，重访时保持视觉一致性；（3）文本触发动态事件——物体交互控制。与 [[HunyuanWorld]] / [[LingBot-World]] 的区别在于把三类控制统一进单一框架，而非单项能力的极致。
- **对比方法/Baselines**: 对比 [[HunyuanWorld]]、[[LingBot-World]]、[[WorldPlay]]，WorldBench 上评估，架构延用 [[RoPE]] + [[KV]] cache。
- **借鉴意义**: 如果做机器人导航或开放世界探索，支持区域重访的交互世界模型是数据生成和训练基础设施的直接候选。
- **锐评**: 108 upvotes 是今天最高，社区认可度实在。但 `has_real_world=False` 是大坑——这是纯视频生成的世界模型，没有任何机器人控制实验，"General-Purpose"的标签在机器人方向还只是 aspiration。Memory-Conditioned 长距离重访是不是真的一致还需要看 WorldBench 具体数字。DreamX Team 匿名发布感觉更像产品 preview，学术性存疑。 🔥

### 3. Mem-World: Memory-Augmented Action-Conditioned World Models for Persistent Robot Manipulation
- **作者**: Zirui Zheng 等
- **机构**: 大连理工大学 + Samsung R&D（北京）
- **链接**: [arXiv](http://arxiv.org/abs/2606.18960v2) | [PDF](https://arxiv.org/pdf/2606.18960v2)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2606.18960v2/figs/pipeline.png)

- **核心方法**: 解决 action-conditioned WM 在长期操作中的状态持久性问题。方法：在 video prediction 基础上加 **Surfel-based 3D 记忆**——InitSurfels 初始化场景点云，UpdateSurfels（用 wrist pose + 深度）持续更新，NMS 去重。推理时 TopK 检索历史 surfel 注入生成上下文，使遮挡物体的状态得以持续追踪。输入：RGB + depth + action；输出：一致性视频预测。Ctrl-World 是同团队的无记忆 baseline。
- **对比方法/Baselines**: 对比 [[Ctrl-World]]（baseline）+ [[DROID]] 数据集上的其他方法；有真实机器人实验（`has_real_world=True`）。
- **借鉴意义**: Surfel 记忆 + action-conditioned WM 的组合对做多步操作规划（尤其涉及遮挡）的人直接有用，代码已开源（GitHub）。
- **锐评**: 大连 + Samsung 的组合不是顶 tier，但思路扎实，3D surfel 记忆比纯 token 记忆（如今天的 MemoryWAM）在几何精度上有优势。主要风险点：UpdateSurfels 的实时计算开销，以及在高动态场景（多物体同时运动）下 NMS 去重 + TopK 检索的精度损失。Surfel 参数估计对深度传感器噪声的鲁棒性也需要验证。 🔥

### 4. ImageWAM: Do World Action Models Really Need Video Generation, or Just Image Editing?
- **作者**: Zhang Yuyang, Zhang Wenyao 等
- **机构**: 上海交通大学 + 东方理工学院 + Tencent Robotics X + 清华大学 + 中关村学院
- **链接**: [arXiv](http://arxiv.org/abs/2606.19531v1) | [PDF](https://arxiv.org/pdf/2606.19531v1)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2606.19531v1/x1.png)

- **核心方法**: 将 WAM 中的视频生成替换为单帧图像编辑（用 [[OmniGen2]] / [[FLUX]] 作为 image editor），只预测下一帧而非整个视频序列，再用该帧 + 下一 action 继续 rollout。规避了视频 WAM 的三个代价：dense multi-frame token、时间一致性约束高、训练计算爆炸。有真实机器人实验（`has_real_world=True`），在 [[LIBERO]]、[[RoboTwin]]、[[RoboTwin2]] 上验证。
- **对比方法/Baselines**: 对比 [[FastWAM]]、[[LingBot]]、[[UniVLA]]、[[BagelVLA]] 等视频 WAM，用 [[DeepSpeed]]/[[ZeRO]] 训练。
- **借鉴意义**: 如果在做 WAM 研究，"图像编辑代替视频生成"这个设计决策的 ablation 直接有用。结论若成立，inference 成本可以大幅下降。
- **锐评**: 今天最犀利的 ablation 类论文，问题提得好。关键疑虑在于多步 rollout 时的误差累积——视频生成有显式时序一致性约束，图像编辑只有隐式约束。5 步以后 ImageWAM 比视频 WAM 漂移是否更严重？真实机器人实验能验证多少步是可靠的？这是需要仔细看实验设计的地方。Tencent Robotics X 参与背书技术落地可行性。 🔥

### 5. Sensorimotor World Models: Perception for Action via Inverse Dynamics
- **作者**: Petr Ivashkov, Randall Balestriero, Bernhard Schölkopf
- **机构**: Max Planck Institute for Intelligent Systems + Brown University + ELLIS Institute + ETH Zürich
- **链接**: [arXiv](http://arxiv.org/abs/2606.20104v1) | [PDF](https://arxiv.org/pdf/2606.20104v1)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2606.20104v1/x1.png)

- **核心方法**: SMWM（Sensorimotor World Model）核心主张：世界表示应由动作相关性塑造，而不是视觉保真度。方法是 [[JEPA]] 风格无解码器 latent 世界模型，用**逆动力学**（给定 s, s'，预测动作 a）作为唯一训练信号——与 [[DynaMo]] 的区别在于逆动力学是主目标而非辅助 loss。无像素解码器省去大量计算。MPC 做规划，实验在 TwoRoom 等仿真环境中。
- **对比方法/Baselines**: 对比 [[DynaMo]]、[[DreamerV3]]（有解码器）、[[TD-MPC]]、[[LeWM]]、[[I-JEPA]] 风格方法，使用 [[MPC]] + [[CEM]] 规划。
- **借鉴意义**: 对做 latent world model for control 的人，无解码器 + 逆动力学的组合在理论上大幅节省训练计算量，值得在自己的任务上验证。
- **锐评**: MPI + Schölkopf 出品，理论框架干净。但 `has_real_world=False`，只有仿真验证。逆动力学的老问题——高维空间中 (s, s') → a 是病态映射（同一对状态可对应多个动作），SMWM 怎么处理这个歧义性？摘要没说清楚，需要看正文数学部分。框架有意思，但实用性有待真实机器人验证。 👀
- 💡 **想精读？** 运行：`读一下 Sensorimotor World Models: Perception for Action via Inverse Dynamics`

### 6. SWAP: Symmetric Equivariant World-Model for Agile Robot Parkour
- **作者**: Kaixin Lan 等
- **机构**: 浙江大学 Center for X-Mechanics + Mirrorme Technology
- **链接**: [arXiv](http://arxiv.org/abs/2606.19928v1) | [PDF](https://arxiv.org/pdf/2606.19928v1)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2606.19928v1/x1.png)

- **核心方法**: 输入：机器人本体感知 + 高度图；在 [[RSSM]] 架构上加对称性约束。SymLoss 强制 latent state 的 Z₂ 对称性（左右镜像等变），等效于把每条训练轨迹 + 其镜像版都纳入训练，数据量翻倍。Eq-Policy 是等变 actor-critic。有真实四足机器人跑酷实验（`has_real_world=True`）。
- **对比方法/Baselines**: 对比无对称约束的 MFRL（Model-Free RL）和 World Model RL，实验在真实四足机器人跑酷上。
- **借鉴意义**: 对做四足运动 world model 的人，SymLoss 是低成本的提升方案——基本可以直接插入任何 RSSM-based pipeline，不改变架构。
- **锐评**: 思路直接，有真实跑酷实验是加分。但 RSSM 是 2019 年的东西，SWAP 的核心 novelty 就是那个 SymLoss，贡献量有限。更关键的问题：跑酷场景有多极端？左右对称性在跑直线时很有用，但在需要不对称动作的弯道、障碍物绕行时 SymLoss 是否会 hurt？这个 tradeoff 需要量化。 👀
- 💡 **想精读？** 运行：`读一下 SWAP: Symmetric Equivariant World-Model for Agile Robot Parkour`

### 7. Current World Models Lack a Persistent State Core
- **作者**: Lu Jinpeng 等
- **机构**: 未知（富化未提取到机构信息）
- **链接**: [arXiv](http://arxiv.org/abs/2606.20545v1) | [PDF](https://arxiv.org/pdf/2606.20545v1)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2606.20545v1/x2.png)

- **核心方法**: WRBench（World-state Reasoning Benchmark），专门测试视角变换（viewpoint intervention）下世界模型的状态持久性。4 层评估维度：场景内容一致性、物体状态跟踪、空间关系保持、物理属性不变性。对 [[Wan-Fun]]、[[HyDRA]]、[[LingBot]]、[[ReCamMaster]] 等主流视频世界模型进行系统评测，核心发现：改变视角后，所有被测模型的状态保持能力均显著下降——"persistent state core"缺失。
- **对比方法/Baselines**: 评测对象包括 [[LingBot]]、[[GeoAdapter]]、[[WorldPlay]]、[[InSpatio]]，检验 viewpoint invariance。
- **借鉴意义**: 如果在做需要多视角一致性的世界模型（机器人仿真、embodied navigation），WRBench 是个很好的验收工具；如果在设计新 WM，这个维度是明确的改进方向。
- **锐评**: 诊断论文本身贡献有限，但这个发现——WM 改变视角后状态"失忆"——确实是没有被充分量化的问题，提出来有价值。机构不明是减分，但如果 WRBench 能开源并被社区采用，这篇就值了。解决方案留给后续工作。 👀
- 💡 **想精读？** 运行：`读一下 Current World Models Lack a Persistent State Core`

### 8. MemoryWAM: Efficient World Action Modeling with Persistent Memory
- **作者**: Sizhe Yang 等
- **机构**: 香港中文大学 + 清华大学 + 浙江大学
- **链接**: [arXiv](http://arxiv.org/abs/2606.20562v1) | [PDF](https://arxiv.org/pdf/2606.20562v1)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2606.20562v1/x1.png)

- **核心方法**: 在 [[DiT]]-based WAM（GigaWorld/MotuBrain 风格）上加 persistent memory tokens，memory 通过 TTT（Test-Time Training）在每次 inference 时按当前观测更新。KV cache 复用降低推理延迟。输入：observation + memory tokens；输出：下一帧预测 + action。与 [[Mem-World]] 的区别：Mem-World 用 Surfel 3D 记忆（几何精确），MemoryWAM 用 token-level 软记忆（更 LLM-style）。有真实机器人实验。
- **对比方法/Baselines**: 对比 [[FastWAM]]、[[GigaWorld]]、[[MotuBrain]]。
- **借鉴意义**: TTT 更新 memory tokens 是个有意思的工程方案，在没有深度传感器的场景下比 Surfel 记忆更容易部署。
- **锐评**: CUHK + 清华团队实力不差，但同日出了 Mem-World（score=9），两篇都在做"WAM + 记忆"，MemoryWAM 的技术路线在几何精度上弱于 Surfel 方案，只是在部署便捷性上有优势。贡献感觉比较 incremental——TTT 更新 memory 不是 MemoryWAM 发明的，DiT memory tokens 也不新鲜。 🫠

### 9. EquiVLA: A General Framework for Rotationally Equivariant Vision-Language-Action Models
- **作者**: Thien-Loc Ha 等
- **机构**: VinRobotics + VinUniversity + DFKI + University of Stuttgart + IMPRS-IS
- **链接**: [arXiv](http://arxiv.org/abs/2606.19784v1) | [PDF](https://arxiv.org/pdf/2606.19784v1)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2606.19784v1/x1.png)

- **核心方法**: 输入：图像 + 语言指令；输出：旋转等变的连续动作序列。将 VLA 拆为两个等变模块：**EquiPerceptor**（SE(2)/SO(2) 群等变视觉特征提取器，保证图像旋转后特征相应旋转）和 **EquiActor**（等变 [[DiT]]-based action head，基于 [[Flow-Matching]]，保证感知旋转后动作相应旋转）。在 [[LIBERO]]、[[CALVIN]]（ABCD split）、[[ALOHA]] 三套 benchmark + 真实机器人（`has_real_world=True`）上验证。
- **对比方法/Baselines**: 对比非等变 VLA（[[OpenVLA]]、[[CogACT]]），以及 [[EquiLLM]] 等等变 LLM 方法；[[LIBERO]] + [[CALVIN]] + [[ALOHA]] 均有数字。
- **借鉴意义**: 如果做需要在任意方向工作的机械臂（如旋转放置、无特定朝向的桌面抓取），EquiVLA 框架是直接可参考的等变 policy 设计。
- **锐评**: 等变性是 VLA 里长期被忽视的问题，EquiVLA 是第一个系统框架，这点实打实。但有几个值得质疑的地方：（1）SO(2) 等变只处理水平面旋转，而真实操作中 SO(3) 旋转（翻转物体、倾斜放置）才是更难的，这个 gap 没有讨论；（2）等变卷积通常比标准卷积慢 2-5x，推理延迟开销没有量化；（3）LIBERO 上的提升有多少来自等变性本身，有多少来自架构调整（DiT + flow matching vs 原始 VLA）？需要细看 ablation。 🔥

### 10. Object-Centric Residual RL for Zero-Shot Sim-to-Real VLA Enhancement
- **作者**: Kinam Kim 等
- **机构**: KAIST + Microsoft Research Asia（Tokyo）+ 东京大学
- **链接**: [arXiv](http://arxiv.org/abs/2606.18953v1) | [PDF](https://arxiv.org/pdf/2606.18953v1)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2606.18953v1/x2.png)

- **核心方法**: 冻结预训练 VLA，在其上训练 object-centric 残差 RL 策略（ResFiT）来纠正 VLA 动作的精度误差。关键设计：用 [[FoundationPose]] 提取目标物体 6DoF 姿态作为 RL 状态（比像素 RL 稳定），在 [[MuJoCo]] 仿真中用 PoseAugment 训练，零样本迁移真实机械臂。与 [[ResiP]] 的区别：ResiP 需要 teacher-student，ResFiT 直接用 foundation pose 省掉这一步。
- **对比方法/Baselines**: 对比 [[ResiP]]（残差 RL baseline）、纯 [[SFT]] 微调，有 PoseAugment ablation；真实机器人 pick-and-place 实验（`has_real_world=True`）。
- **借鉴意义**: 如果 VLA 在 precision manipulation 上差，ResFiT 是个轻量 plug-in——不需要重训 VLA，只需要小残差网络 + FoundationPose。
- **锐评**: KAIST + MSRA Tokyo 保障质量，思路清晰。但软肋是依赖 [[FoundationPose]]——透明物体、高反光、novel objects 上 FoundationPose 会挂，ResFiT 跟着挂。残差 RL 的 training stability 历来是问题，实验里的物体种类和姿态多样性是判断 generalization 的关键数字。 👀
- 💡 **想精读？** 运行：`读一下 Object-Centric Residual RL for Zero-Shot Sim-to-Real VLA Enhancement`

- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2606.20246v1/images/CLS_Pruning_v2.png)

- **核心方法**: 用 [[CKA]]（Centered Kernel Alignment）分析 VLA 微调前后各层的表示变化，发现大多数层在微调中几乎不动，需要更新的层集中在靠近 action head 的后段。基于此提出 CLP（Coarse Layer Pruning）：只微调后 K 层（K ≪ 总层数），其余冻结。在 [[OpenVLA]]、[[SmolVLA]]、[[CogACT]] 等模型上，[[LIBERO]]、[[SimplerEnv]]、[[ALOHA]]、[[RoboCasa]] 四个 benchmark 均有验证，有真实机器人实验（`has_real_world=True`）。
- **对比方法/Baselines**: 对比全参数微调、[[LoRA]]、[[MoLe]]（Mixture of Layers）、[[SpecPrune]] 等参数高效微调方法。
- **借鉴意义**: 直接实用——如果在微调 VLA，试试只调最后几层，能省不少计算。VinRobotics 今天刷了两篇（EquiVLA 也是），团队产出率高。
- **锐评**: CKA 分析工具本身不是新的，但用来系统分析 VLA 层重要性是个有价值的 empirical study。结论"只需调后 K 层"听起来反直觉但可能成立，因为 action 输出是局部的，早期层的语言视觉理解不需要变。但通用性是最大问题：不同任务（LIBERO vs ALOHA）的"需要调的层"是否一致？如果因任务而异，CLP 就需要 per-task 搜索 K，收益打折。 👀
- 💡 **想精读？** 运行：`读一下 Finetuning Vision-Language-Action Models Requires Fewer Layers Than You Think`

### 14. EventVLA: Event-Driven Visual Evidence Memory for Long-Horizon Vision-Language-Action Policies
- **作者**: Ganlin Yang 等
- **机构**: 中国科技大学 + 上海 AI 实验室 + 上海交通大学 + 华为 + 大连理工 + 港大 + 清华 + 北大
- **链接**: [arXiv](http://arxiv.org/abs/2606.20092v1) | [PDF](https://arxiv.org/pdf/2606.20092v1)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2606.20092v1/x1.png)

- **核心方法**: 输入：长时序 RGB + 语言指令；解决长程操作中遮挡/状态丢失问题。引入 KEM（Key Event Memory）：VLM（QwenOFT）检测关键事件（物体状态改变、任务进度节点），仅在关键事件触发时更新记忆（FIFO + NMS 去重），VLA 推理时用 cross-attention 检索相关记忆。与 [[MemoryVLA]] 的区别：MemoryVLA 均匀采样历史帧，EventVLA 是事件驱动的稀疏存储，理论上存储和计算更高效。有真实机器人实验（`has_real_world=True`）。
- **对比方法/Baselines**: 对比 [[MemoryVLA]]、[[OpenVLA]] 在 [[RoboTwin]] 和真实机器人上。
- **借鉴意义**: KEM 的事件驱动设计对做长程多步操作（组装、烹饪序列）有直接参考价值，稀疏记忆比全量历史高效。
- **锐评**: 想法合理，有真机实验。但事件检测依赖 VLM 的正确性——如果 QwenOFT 漏检了关键事件，记忆有 gap，策略跟着失败，这是 cascading failure 风险。8 家机构联合（USTC + SHAILab + SJTU + HKU + THU + PKU...）是个红旗信号，资源充足但可能是凑算力的灌水模式。看 benchmark 上的真实提升幅度和消融。 👀
