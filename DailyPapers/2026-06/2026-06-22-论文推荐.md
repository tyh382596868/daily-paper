### 1. Reward as An Agent for Embodied World Models (SAGE)
- **作者**: 未提取
- **机构**: 未知
- **链接**: [arXiv](https://arxiv.org/abs/2606.19990) | [PDF](https://arxiv.org/pdf/2606.19990)
- **来源**: 📄 arXiv 关键词检索
- 📒 **笔记**: [RewardAgent](../论文笔记/1-生成模型/RewardAgent.md)

![](https://arxiv.org/html/2606.19990v1/x1.png)

- **核心方法**: SAGE 把 reward model 从静态打分器改造为主动探索智能体。现有 RL 微调世界模型的方案依赖保守 rollout（近分布采样），SAGE 的 reward agent 用 [[GRPO]] 优化自身策略，主动提出"高信息量"的 rollout 请求，迫使 [[DynDiff]] 世界模型走出训练分布边界。通过 [[CFG]] 控制动态强度，实现 dynamic-aware 探索。在 [[AgiBotWorld]] 双臂数据集上验证，benchmark 为 TaskEval。
- **对比方法/Baselines**: 基础模型 [[DynDiff]]（其本身的世界模型）；借鉴了 [[UnifiedReward]] 做视频对齐；在 [[AgiBotWorld]] 上对比标准保守 rollout 方案
- **借鉴意义**: 对做机器人世界模型 RL 微调的人直接有用——把 reward model 当 agent 主动生成 curriculum 的思路可迁移到任何 action-conditioned video generation 训练框架，尤其是数据稀缺场景
- **锐评**: 核心 idea 很聪明：reward agent 既评分又主动探索，打破了"生成 → 评分 → 微调"的被动循环。但摘要没说清 SAGE agent 本身如何训练——reward signal 从何来？如果仍依赖人工标注，那只是套了一层壳。仅在 AgiBotWorld 单数据集验证，泛化性存疑。方法有意思，细节需看全文确认。 🔥

### 4. Through the PRISM: Preference Representation in Intermediate States of Video Diffusion Models

- **机构**: City University of Hong Kong, Columbia University, CUHK
- **链接**: [arXiv](https://arxiv.org/abs/2606.20310) | [PDF](https://arxiv.org/pdf/2606.20310)

![](https://arxiv.org/html/2606.20310v1/x1.png)

- **核心方法**: PRISM 发现视频扩散模型在去噪过程的中间时间步（noisy intermediate states）已包含足够的偏好判别信息，无需解码到 clean 像素即可做视频质量评分。在 [[CogVideoX]] 的中间激活上接一个轻量级判别头，避免 VAE 解码的计算开销。推理时可在 [[BoN]]（Best-of-N）搜索中用中间态剪枝低质量候选，节省整体推理成本。
- **对比方法/Baselines**: 对比 [[VideoScore2]]、[[UnifiedReward]]、[[VideoReward]]；以 [[CogVideoX]] 为 backbone
- **借鉴意义**: 对做 video generation + RLHF 或 inference-time scaling 的人有价值：不完整生成就能评分，大幅加速 BoN 或 reward-guided generation
- **锐评**: 核心发现很 elegant——扩散中间态更接近 representation space，用它做判别在理论上站得住。但有两个疑问：不同时间步的判别能力差异有多大？选哪个步是新的超参数。其次，方法依赖 CogVideoX 的特定架构，泛化到 HunyuanVideo、Wan 等是否需要重训？ 👀

### 7. Frequency-Aware Flow Matching for Continuous and Consistent Robotic Action Generation (FAFM)
- **作者**: 未提取
- **机构**: 未知
- **链接**: [arXiv](https://arxiv.org/abs/2606.20135) | [PDF](https://arxiv.org/pdf/2606.20135)
- **来源**: 📄 arXiv 关键词检索
- 📒 **笔记**: [FAFM](../论文笔记/3-Robotics/VLA/FAFM.md)

![](https://arxiv.org/html/2606.20135v1/figure/intro_v4.png)

- **核心方法**: FAFM 针对 action chunking 的两个问题——chunk 边界不连续和高频抖动——将动作序列用 [[DCT]]（离散余弦变换）投影到频域，flow matching 在频域空间内操作。低频分量对应整体轨迹平滑度，高频分量对应精细调整，FreqPolicy 加权损失对不同频率施加不同约束。在 [[LIBERO]]、LapGym 和真实机器人上验证（`has_real_world=True`）。
- **对比方法/Baselines**: 对比 [[DP]]（Diffusion Policy）及标准 flow matching；借鉴 [[FreqPolicy]] 的频域先验；在 [[LIBERO]] 和 LapGym 做消融
- **借鉴意义**: 直接有用。如果你在用 diffusion/flow policy 做 manipulation 并遇到 chunk 边界抖动问题，这篇值得精读
- **锐评**: DCT 表示本身就是正交分解，不同频率对应不同运动特征，用频域加权损失是合理的归纳偏置——idea elegant。真实机器人实验有说服力。唯一疑问：频域 flow matching 的推理速度如何？DCT/IDCT 的额外计算开销在实时控制场景下的延迟需要报出来。 🔥
- 💡 **想精读？** 运行：`读一下 Frequency-Aware Flow Matching for Continuous and Consistent Robotic Action Generation`

### 8. Start Right, Arrive Right: Asynchronous Execution via Initial Noise Selection (PAINT)
- **作者**: 未提取
- **机构**: VinRobotics, VinUniversity, DFKI, University of Stuttgart, IMPRS-IS
- **链接**: [arXiv](https://arxiv.org/abs/2606.19774) | [PDF](https://arxiv.org/pdf/2606.19774)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2606.19774v1/x1.png)

- **核心方法**: PAINT（Prefix-Anchored Initial Noise Transport）通过选择初始噪声保证异步执行下 action chunk 的连续性。生成下一个 chunk 时，用 OT（最优输运）找一个初始噪声，使 flow matching 生成的新 chunk 前几帧与当前执行 chunk 末几帧平滑衔接。用 [[TensorRT]] 加速，在真实机器人上测试延迟改善效果（`has_real_world=True`）。
- **对比方法/Baselines**: 对比 Slide-Naive（朴素滑窗）等异步执行策略；用 OT 做噪声初始化
- **借鉴意义**: 对做 real-time deployment 的 flow policy 或 diffusion policy 是直接可用的工程技巧。chunk 边界连续性是落地必须面对的问题
- **锐评**: 问题定义很实际——flow policy 推理慢，机器人不能等。OT 选初始噪声比直接 padding 或插值有更强的理论依据。但 OT 求解本身有计算开销，[[TensorRT]] 加速的延迟数字需要看全文。方法依赖 flow matching 架构，不能直接迁移到 diffusion policy。 👀
- 💡 **想精读？** 运行：`读一下 Start Right, Arrive Right: Asynchronous Execution via Initial Noise Selection`

![](https://arxiv.org/html/2606.19897v1/x1.png)

- **核心方法**: ExS2D 层次框架让单臂 VLM agent 自动生成双臂协调动作：SubGen 模块用 MLLM 把任务分解为子任务并分配给两只手臂，[[SAM]] + [[OWL]] 做物体感知，最终在 [[ALOHA]] 双臂平台执行。有真实双臂实验（`has_real_world=True`）。

### 14. Generating Robot Hands from Human Demonstrations

### 15. Belt-Finger: An Affordable Soft Belt-Driven Gripper for Dexterous In-Hand Manipulation

### 17. TaCauchy: An Extensible FEM Framework for Vision-Based Tactile Simulation
- **作者**: 未提取
- **机构**: 未知
- **链接**: [arXiv](https://arxiv.org/abs/2606.20426) | [PDF](https://arxiv.org/pdf/2606.20426)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2606.20426v1/x1.png)

- **核心方法**: TaCauchy 用有限元法（FEM）结合 Cauchy stress tensor 描述接触力学，集成到 GPU 加速机器人仿真框架（基于 UIPC 物理引擎），支持 [[GelSight]]、[[DIGIT]] 等视觉触觉传感器仿真。提供比 [[TacIPC]]、[[TacEx]]、[[DIFFTACTILE]] 更准确的应力场和更可扩展的传感器接口。
- **对比方法/Baselines**: 对比 [[TacIPC]]、[[TacEx]]、[[UniVTAC]]、[[DIFFTACTILE]]、[[TacSL]]
- **借鉴意义**: 触觉仿真是 tactile sim-to-real 的关键基础设施，做 dexterous manipulation 且使用 GelSight/DIGIT 类传感器的人值得关注
- **锐评**: FEM 做触觉仿真精度更高，Cauchy stress 显式计算是合理选择。关键疑问：FEM 计算量大，GPU 加速能否支撑实时 RL 训练（通常需要 4096+ 并行环境）？对比基准选择合理，但缺了端到端 sim-to-real transfer 验证——仿真精度高不等于 sim-to-real gap 小。 👀
