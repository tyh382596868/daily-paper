### VLA / Embodied Reasoning

#### 3. 3DThinkVLA: Endowing Vision-Language-Action Models with Latent 3D Priors via 3D-Thinking-Guided Co-training
- **作者**: Jiaxin Shi, Xidong Zhang, Fucai Zhu, Zhe Li, Siyu Zhu, Weihao Yuan
- **机构**: 上海交大, 哈工大, 南洋理工, 复旦, 南京大学, 大湾区大学
- **链接**: [arXiv](https://arxiv.org/abs/2606.04436) | [PDF](https://arxiv.org/pdf/2606.04436)
- **来源**: 📄 arXiv 关键词检索
- 📒 **笔记**: [[3DThinkVLA]]

![](https://arxiv.org/html/2606.04436v1/x1.png)

- **核心方法**: 输入纯 2D 图像 + 语言指令，输出动作，但训练时让 VLA 学会"隐式"做 3D 推理。三件套：(1) **latent 3D geometry perception** 用 3D foundation model 做中间层特征对齐，把几何先验灌进 VLM backbone；(2) **online 3D reasoning distillation** 引入一个 [[CLS Token|reasoning anchor token]]，在 VLM 共训时作为首输出 token 编码空间先验，在 VLA 训练时作为 task 和 action 之间的中间 token，把老师的 [[CoT]] 推理蒸馏给学生，但**学生最终不需要生成文本 CoT**；(3) **spatially augmented action integration** 把几何特征和推理特征注入 action query token。部署只保留 lightweight adapter，没有 3D 传感器和 3D foundation model。
- **对比方法/Baselines**: 在 [[LIBERO]]、[[LIBERO]]-PLUS、[[SimplerEnv]] 三个 benchmark 和真机上做对比，对标显式 3D VLA（如 [[3DFlowAction]]、点云注入到 VLM/action head 的方法）；借鉴 [[OFT]] 思路做参数高效微调；与 [[VLM]] / [[VLA]] 标准范式做改造对比
- **借鉴意义**: 对做 VLA 的人非常实用——**把 3D 先验"训练时蒸馏、推理时丢弃"**的范式可以直接迁移。如果你正在用 OpenVLA / π0 这类 2D-only VLA，3DThinkVLA 给的中间层对齐 + anchor token 蒸馏是一个低风险的加 buff 配方
- **锐评**: 这是今天 VLA 区最实在的一篇。三个组件都对应了具体技术问题（特征对齐 / CoT 蒸馏 / action 注入），不是堆砌。`has_real_world=true` 且号称在 LIBERO / SimplerEnv / 真机都做 SOTA，**如果 SOTA 数字扛得住 [[BenchAudit]] 的诊断（同一份榜单今天也被锤了），这篇就是可以直接抄的范式**。要质疑的点：reasoning anchor token 这种"单 token 蒸馏一切"的设计上限有限，task 复杂度一高很可能崩；3D foundation model 选哪个、对齐到哪层，这些 ablation 必须看完。结论：必读级别。🔥
- **关联笔记**: [[VLA]] / [[OpenVLA]] / [[CoT-VLA]] 是直接对比对象；[[3DFlowAction]] / [[CoT]] / [[CLS Token]] 是核心技术依赖
- 💡 **想精读？** 运行：`读一下 3DThinkVLA: Endowing Vision-Language-Action Models with Latent 3D Priors`

### World Model + Robotics（核心战场）

#### 4. MAD: Mapping-Aware World Models for Agile Quadrotor Flight
- **作者**: Xinhong Zhang, Runqing Wang, Yunfan Ren, Ding Yu, Boyu Zhou, Jian Sun, Fang Deng, Jie Chen, Gang Wang
- **机构**: 作者列表指向国内多家高校（北理工 / 中山大 / 港科广 等）
- **链接**: [arXiv](https://arxiv.org/abs/2606.04534) | [PDF](https://arxiv.org/pdf/2606.04534)
- **来源**: 📄 arXiv 关键词检索
- 📒 **笔记**: [[MAD]]

![](https://arxiv.org/html/2606.04534v1/x1.png)

- **核心方法**: 输入深度图 + 本体感知，输出无人机控制指令，中间过一个 geometry-aware 的 [[基于模型的强化学习|world model]]。关键改造：**重建目标不是原始图像，而是 robocentric occupancy grid map (OGM) + visibility grid map (VGM) + 本体状态**——这迫使 latent 编码局部几何、可见性历史和 ego-motion，而不是被纹理噪声带跑。基于 [[DreamerV3]] 的 RSSM 结构，在 DiffAero 仿真器里用 GPU 并行的地图构造模块做高吞吐监督。策略有三种用法：基于 imagination 的 MAD-Dreamer，和把 latent 当 feature extractor 的 [[PPO]] / [[SHAC]] 变体
- **对比方法/Baselines**: 借鉴 [[DreamerV3]] / [[RSSM]] 的 latent dynamics；用 [[PPO]] 和 SHAC 做策略训练；与 YOPO 和 EGO 这类传统 agile 飞行 baseline 做对比；与纯 vision-only baseline 比成功率和速度
- **借鉴意义**: 对所有做 world model 的人都该看——**重建目标改造**比"加大网络"重要得多。把 reconstruction target 从像素换成 task-relevant geometry，这是 [[Compositional World Models]] 那条路的延伸。如果你做 manipulation 也想用 WM，可以借这个思路：让 latent 显式重建 affordance 或 contact 而不是 RGB
- **锐评**: 这篇是今天 WM 区最具体的一篇。`has_real_world=true`，真机森林环境跑到 5.05 m/s，仿真到 9.66 m/s——数字硬。OGM/VGM 监督这个 idea 不算原创（[[OA-WAM]] 早就在用类似的 affordance 监督），但**把它和 DreamerV3 这条主线结合并在 agile flight 任务上跑通**有工程价值。可质疑的点：MAD-Dreamer 真打过 PPO/SHAC 变体吗？还是说 imagination 学习实际不如直接拿 latent 当 feature？这是 WM 文章普遍的尴尬，需要看正文表格确认。结论：必读，是今天 WM + 真机 deploy 最扎实的样本。🔥
- **关联笔记**: [[DreamerV3]] / [[RSSM]] / [[基于模型的强化学习]] 是直接前置；[[OA-WAM]] / [[Compositional World Models]] 是 task-aware reconstruction 方向的同路人
- 💡 **想精读？** 运行：`读一下 MAD: Mapping-Aware World Models for Agile Quadrotor Flight`

#### 5. Generalization of World Models under Environmental Variability for Vision-based Quadrotor Navigation
- **作者**: Luca Zanatta, Grzegorz Malczyk, Kostas Alexis
- **机构**: Norwegian University of Science and Technology
- **链接**: [arXiv](https://arxiv.org/abs/2606.05015) | [PDF](https://arxiv.org/pdf/2606.05015)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2606.05015v1/x1.png)

- **核心方法**: 这是一个**系统性研究**而不是新方法。在 vision-based 四旋翼导航任务上，用不同 randomness 等级训练 [[DreamerV3]] world model（基于 [[RSSM]]），然后做 cross-environment 验证，覆盖 SSL pretraining 和 RL fine-tuning 两阶段。最后部署到真机做开放环境飞行，包括一个 open-loop run：模型只看 2.5 秒真实传感器，之后所有传感器切断，纯靠 imagination 飞 12 米
- **对比方法/Baselines**: 基于 [[DreamerV3]] / [[RSSM]] 做训练框架；研究 discrete latent size 和 training-sequence length 这两个超参的影响；用 [[OOD]] 评估做 cross-environment 验证
- **借鉴意义**: 实验型论文，但给做 WM 的人提供了**两个反直觉发现**：(1) SSL pretraining 阶段的鲁棒性比 RL 阶段的策略性能更能预测 sim-to-real 成功率；(2) discrete latent size 和 sequence length 是质量的决定因素。如果你在做 WM-based policy 而苦于 sim-to-real 不稳定，这两条经验有指导意义
- **锐评**: 这种 "ablation paper" 容易写水，但这篇做了开放环境真机部署而且号称 12 米 imagination-only 飞行，验证强度够。最有意思的发现是**"在仿真里夺榜的模型在真机失败，但在 cross-env SSL 验证里通用的模型反而成功"**——直接打脸"只看 simulation success rate"的评估惯例，这一点跟今天 [[BenchAudit]] 的批判合流。质疑：N=多少？模型变化是否只是 hyperparameter sweep？方差有没有控制？需要看正文表格。结论：值得看，对实验设计有启发。👀
- **关联笔记**: [[DreamerV3]] / [[RSSM]] / [[基于模型的强化学习]] 是基础；[[sim-to-real]] / [[BenchAudit]] 是同周的方法论同路人
- 💡 **想精读？** 运行：`读一下 Generalization of World Models under Environmental Variability`

#### 6. WAM-Nav: Asymmetric Latent World-Action Modeling for Unified Visual Navigation
- **作者**: Ning Yang 等
- **机构**: 南京大学, 中科院自动化所, 国科大, 国防科大, 清华大学, FiveAges 等
- **链接**: [arXiv](https://arxiv.org/abs/2606.04907) | [PDF](https://arxiv.org/pdf/2606.04907)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2606.04907v1/corl_2026_template_cameraready/figures/Introduction.png)

- **核心方法**: 输入 RGB 序列 + episode 历史，输出长 horizon 动作和短 horizon 视觉预测。核心是**共享一个 [[DiT|Diffusion Transformer]] 做 asymmetric joint diffusion**——同时去噪 long-horizon action 和 short-horizon visual foresight，把"先想再做"压成一次 forward。配套 dual-stream contextual conditioning（episode-level ego-motion + 序列视觉观测）和统一 goal alignment 模块，让 Image-Goal / Point-Goal / No-Goal exploration 在单策略里都能跑
- **对比方法/Baselines**: 借鉴 [[DiT]] 架构；与 NavDP（reactive 导航策略）做对比；在 ClutterScenes 和 InternScenes 上评估，指标包括 [[SR]] / [[SPL]]；做 zero-shot sim-to-real 真机部署
- **借鉴意义**: 对做 latent world-action joint modeling 的人很有用。Asymmetric horizon（action 长 / vision 短）这个 trade-off 设计是合理的——如果你做 manipulation 也想加 visual foresight，不必让 vision 跟 action 同 horizon，可以学这个做法
- **锐评**: 思路漂亮：把 visual imagination 和 action generation 塞进同一个 DiT，避免分模块的 error accumulation。`has_real_world=true`，85% 真机 success rate 数字漂亮。要质疑的点：(1) "Asymmetric" 到底是 attention mask 设计还是 loss weight？光看摘要看不出技术深度，可能是工程层面的 trick；(2) Image-Goal 提升 15.7% 显著，但 Point-Goal 只提 3.3%，可能 method 对 goal 类型不够鲁棒；(3) 跟 [[Drive-JEPA]] / [[OA-WAM]] 类似想法的差异需要在正文里清晰交代。结论：值得看，是 latent foresight 这条线今天最具体的样本。👀
- **关联笔记**: [[DiT]] / [[Drive-JEPA]] / [[OA-WAM]] / [[WLA]] 是方法路径同路人；[[sim-to-real]] 是评估场景
- 💡 **想精读？** 运行：`读一下 WAM-Nav: Asymmetric Latent World-Action Modeling`

#### 8. DRIFT: A Residual Flow Adapter for Decoding Continuous Outputs in Vision-Language Models
- **作者**: Zhuoming Liu, Jinhong Lin, Kwan Man Cheng, Lin Zhang, Shayok Bagchi, Yin Li
- **机构**: 未在 abs 页明示
- **链接**: [arXiv](https://arxiv.org/abs/2606.05758) | [PDF](https://arxiv.org/pdf/2606.05758)
- **来源**: 📄 arXiv 关键词检索

- **核心方法**: 输入预训练 VLM 的 latent，输出连续值（时序边界、机器人动作等）。架构是 **base predictor + flow matching refinement**——base 出粗估计，flow 学一个残差分布迭代精炼。把"全局输出分布建模"转化成"在 strong prior 周围学局部残差分布"，简化优化

- **关联笔记**: [[VLA]] / [[CausVid]] / [[Action Expert]] 是方法路径

### Sim-to-Real / Cross-Embodiment

#### 9. TAM: Torque Adaptation Module for Robust Motion Transfer in Manipulation
- **作者**: Dongwon Son 等
- **机构**: KAIST, Allen Institute for AI, University of Washington, University of Toronto
- **链接**: [arXiv](https://arxiv.org/abs/2606.06218) | [PDF](https://arxiv.org/pdf/2606.06218)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2606.06218v1/figures/deploy_v12.png)

- **核心方法**: 输入 policy 的低层 torque 命令 + 本体感知历史，输出"修正后的 torque"。TAM 是一个夹在 controller 和真机 torque interface 之间的薄层模块：(1) history encoder 把 proprioceptive 历史编成 latent；(2) torque adapter 算 residual torque correction。**TAM 只依赖本体感知不依赖策略观测和 action space**，所以同一份 TAM 权重可以适配 joint target / EE target / 直接 torque 三种 policy。训练完全在 randomized sim 里做：multi-robot pretrain + robot-specific finetune（无真机数据）
- **对比方法/Baselines**: 与 online system identification (SysID) 和 [[RMA]] 做 zero-shot 真机对比；策略来源覆盖 [[RL]] (vision-based box pushing)、[[BC]] (flip policy)、[[MPC]] (球-板平衡) 三种范式；用 [[MuJoCo]] 做 sim
- **借鉴意义**: 这个工作对所有做 manipulation policy 部署的人都有用。**把 domain randomization 的负担从 policy 转移到 adapter**这个想法很巧——你的 policy 可以专心学任务，adapter 专心吸收 sim-to-real gap
- **锐评**: 解耦设计漂亮，是 [[RMA]] 思路的演进版本——RMA 在 policy 里学 latent，TAM 在 controller 后再加一层。对比 SysID 和 RMA 这两个 baseline 选得到位。可质疑的点：(1) "torque 接口" 的假设很强，很多商业机器人（Franka 算少数）不开放 direct torque control；(2) 三个任务（push / flip / balance）任务多样但都偏 dynamic motion，对 quasi-static 的 pick-place 这种主流任务可能用不上；(3) "Allen AI 内部 intern 项目"通常算工程探索，不一定是大规模 SOTA 主推。结论：值得看，思路可借鉴。👀
- **关联笔记**: [[RMA]] / [[MPC]] / [[MuJoCo]] / [[sim-to-real]] / [[Franka 研究臂]] 是直接关联
- 💡 **想精读？** 运行：`读一下 TAM: Torque Adaptation Module for Robust Motion Transfer`

#### 12. DexFuture: Hierarchical Future-State Visuomotor Targeting for Bimanual Dexterous Tool Use

- **机构**: 未在 abs 页明示（作者多为 UCSD 系）
- **链接**: [arXiv](https://arxiv.org/abs/2606.05699) | [PDF](https://arxiv.org/pdf/2606.05699)

## 今日趋势

**latent foresight 正在成为新的 standard pattern**：MAD 重建 occupancy/visibility、WAM-Nav 同出 action + vision、3DThinkVLA 蒸馏 3D 推理 anchor、DRIFT 用 flow 做 residual refinement——四篇看似无关，但共同信号是"reactive 不够，policy 必须在 latent 里先想再做"。同一时间，[[BenchAudit]] 这种 community 清扫工作出现，说明大家也意识到现有评估扛不住这一代方法的飞快迭代。humanoid 区今天的明显问题是**方法路径同质化**——distill + WBC + MoE 已经成模板，下半年要看的是有没有人真正突破这条路径。
