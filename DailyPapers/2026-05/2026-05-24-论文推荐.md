### 1. LongCat-Video Technical Report
- **链接**: [arXiv](https://arxiv.org/abs/2510.22200) | [PDF](https://arxiv.org/pdf/2510.22200)
- **来源**: 🔥 HF Trending，⬆️ 35

> ⏪ **再推提醒**：这篇在 2026-05-23 推荐过

![](https://arxiv.org/html/2510.22200/x1.png)

- **核心方法**: 美团 LongCat 团队推出的 13.6B 参数视频生成基础模型。架构是单个 [[DiT]] 同时处理 T2V / I2V / Video-Continuation 三个任务（任务 token 区分），通过在 Video-Continuation 任务上预训练拿到长时序一致性的"世界模型雏形"。推理用 coarse-to-fine 时空生成 + [[滑动窗口注意力|Block Sparse Attention]]，单机分钟级吐 720p 30fps 视频。训练后期用 Multi-Reward [[GRPO]]（[[RLHF]]）多奖励对齐画质、运动质量、物理合理性。
- **对比方法/Baselines**: 显式对标 [[Wan2.1]]、[[Wan2.2]]、PixVerse、Veo 等闭源模型；继承 [[FLUX]]/[[DiT]] 架构系；GRPO 训练继承 [[CausVid]] 路线
- **借鉴意义**: 把"视频生成 → 世界模型"那条路又往前推了一步——明确把 Video-Continuation 当核心预训练目标，等于承认了"长 horizon temporal coherence"才是 WM 的真问题。13B 是当前开源 DiT 里最大的一档，适合作为 embodied 视频世界模型的 backbone 候选
- **锐评**: 中文社区难得一篇正经的开源视频基础模型 report，工程含量超过研究含量——架构无新意（DiT + sparse attention 老配方），数据 pipeline 才是真东西。问题：720p 30fps "minutes-long" 没说具体多少分钟、什么显存、推理 latency 多少；report 里 multi-reward GRPO 写了一大段但 reward model 训练数据没披露。跟 [[Wan2.2]]、[[LTX-2]] 比真正的 advantage 在哪没说清。但如果开源权重质量 OK，做 embodied policy 时换 backbone 是很划算的事。👀
- **关联笔记**: [[Wan2.2]]、[[LTX-2]] 都是同档位视频 DiT；做 WM 的话直接对标 [[Vid2World]]、[[WMPO]]

## 🧠 长序列 / 线性注意力

### 5. Gated DeltaNet-2: Decoupling Erase and Write in Linear Attention
- **作者**: Hatamizadeh Ali, Choi Yejin, Kautz Jan
- **机构**: NVIDIA
- **链接**: [arXiv](https://arxiv.org/abs/2605.22791) | [PDF](https://arxiv.org/pdf/2605.22791)
- **来源**: 🔥 HF Trending，⬆️ 21
- 📒 **笔记**: [[GatedDeltaNet-2]]

> ⏪ **再推提醒**：这篇在 2026-05-23 推荐过

- **核心方法**: 线性注意力的核心痛点是"压缩的 recurrent state 怎么编辑而不破坏已有关联"。[[Gated DeltaNet]] 用 delta-rule "先读后写" 来局部更新，Kimi Delta Attention (KDA) 加了 channel-wise decay 让遗忘更精细——但两者都用同一个标量 gate 控制 "key 侧擦除多少 + value 侧写入多少"。GatedDeltaNet-2 直接把这俩解耦：channel-wise erase gate $b_t$ 和 channel-wise write gate $w_t$ 分别控制。论文给出 fast-weight update 视角的解释，配合 chunkwise [[WY 算法|WY]] 把 channel-wise decay 吸收进 asymmetric erase factor，保持 chunk 并行训练复杂度不变。在 NIAH-1 / NIAH 多键检索、SISO/MIMO 任务上比 [[Gated DeltaNet]] 和 KDA 都有提升。
- **对比方法/Baselines**: 直接对比 [[Gated DeltaNet]]、KDA（Kimi Delta Attention）；跟 [[softmax 注意力|Softmax Attention]]、[[滑动窗口注意力|SWA]] 在 long-context 任务上比；理论上跟 [[Mamba]]、[[Frame-wise Gated DeltaNet]] 同属"压缩状态序列模型"家族
- **借鉴意义**: 对做"世界模型 + 长 horizon memory"的工作直接相关——VLA / WM 里那些"压缩历史轨迹"的 memory module 现在普遍依赖 GatedDeltaNet 或其变种，erase/write 解耦意味着可以做更精细的 memory editing。如果在 [[MemoryVLA]]、[[VLA-JEPA]] 这类 memory-augmented VLA 上替换 mixer，可能能拿到免费的 long horizon 提升
- **锐评**: NVIDIA 出品的"小步快跑"工作——单点改进很干净，理论也讲得通。但论文 framing 有点"为改而改"：scalar tie 真的是 bottleneck 吗？ablation 里 "channel-wise erase only" / "channel-wise write only" 的对比应该是主菜，但篇幅太短。WY chunkwise 实现细节给得详细，工程价值大于理论价值。整体属于 sequence modeling 圈内必看，跨圈影响要看后续 VLA / 世界模型组多快接住。🔥
- **关联笔记**: [[Gated DeltaNet]]、[[Frame-wise Gated DeltaNet]] 是直接前作；放进 [[潜空间世界模型]] / [[Hybrid KV Cache]] 路线
- 💡 **想精读？** 运行：`读一下 GatedDeltaNet-2`

### 7. Learning Structural Latent Points for Efficient Visual Representations in Robotic Manipulation
- **作者**: Jiang Yicheng, Wang Jiaxu, He Junhao, Gan Zesen, Li Junhao, Zhang Qiang, Sun Jingkai, Cao Jiahang, Sun Mingyuan, Yue Xiangyu, Shao Qiming
- **机构**: The Hong Kong University of Science and Technology, HKUST (Guangzhou)
- **链接**: [arXiv](https://arxiv.org/abs/2605.21258) | [PDF](https://arxiv.org/pdf/2605.21258)
- **来源**: 📄 arXiv 关键词检索
- 📒 **笔记**: [[StructLatentPoints]]

![](https://arxiv.org/html/2605.21258v1/x1.png)

- **核心方法**: 提出"结构化潜点（Structural Latent Points）"作为 manipulation 视觉表征。在 point cloud autoencoder 的潜空间里塞一个 point-wise VAE，同时正则化 point 的 feature 和坐标到 Gaussian 先验——产物是介于隐式（[[NeRF]] / 隐式神经场）和显式（点云 / 3DGS）之间的混合表征：保留粗结构性，但不被精确几何束缚。Pretraining 任务是用 lightweight [[3D Gaussian Splatting]] rendering pipeline 重建 multi-view。下游 policy 用 [[ACT (Action Chunking Transformer)]] 接这个 latent。
- **对比方法/Baselines**: 显式对比 [[PonderV2]]（NeRF-based pretraining）、SPA、[[VC-1]]、纯 [[3D Gaussian Splatting]] 表征；在 [[ManiSkill]]2 上测下游 manipulation 任务
- **借鉴意义**: 跟笔记库里 [[GaussianDream]]、[[Cosmos-Policy]] 那条"3D 表征预训练给 manipulation policy"的路线非常对口。"hybrid latent + GS rendering 监督"这套思路如果 ablation 站得住，可能比纯 [[NeRF]] / 纯 [[3DGS]] 表征都好——前者重几何精度，后者重渲染速度，hybrid 两边都要
- **锐评**: idea 干净——抓住了"manipulation 不需要像素级几何，但要比 ViT feature 多一点结构"这个 sweet spot。但选择 [[ManiSkill]]2 而非 LIBERO / RoboCasa 作为评测，意味着无法直接跟最新的 VLA baseline 对比；real-world 实验论文没明说占多大篇幅，需要看 PDF 确认是不是又是 sim-only。另外 "structural latent points" 这个命名稍微卖弄——本质就是 VAE-regularized point feature，没必要起新名字。但方向对，值得跟 [[GaussianDream]] 一起读。🔥

### 9. PGDG: Physically Grounded Data Generation for Robust Bimanual Policy Learning from a Single Demonstration
- **作者**: Dai Cunxi, Chang Haoran, Nisal Aditya, Kumar Rahul, Chen Guofei, Chen Tao, Qin Yuzhe, Shi Guanya
- **机构**: Robotics Institute, CMU; Dexmate
- **链接**: [arXiv](https://arxiv.org/abs/2605.21710) | [PDF](https://arxiv.org/pdf/2605.21710)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2605.21710v1/x1.png)

- **核心方法**: 从单条 demo 出发，迭代地生成 contact-rich bimanual 操作数据。Sampler 是物理 grounded（IsaacLab 风的物理仿真做 rollout），curator 选 "informative + non-redundant + recoverable" 的样本回写到采样分布，逐步覆盖 recovery mode。对 risky state 用 short-horizon 采样控制（[[CEM]] 类）做 corrective relabel。Policy 用 [[ACT (Action Chunking Transformer)]] / behavior cloning。在 4 个 bimanual 任务（RotateBox-Pitch 等）上做 sim + real 验证，RotateBox-Pitch sim 从 38% 提到 93%，real-world 也有显著提升。
- **对比方法/Baselines**: 显式对比 [[MimicGen]]（spatial-only augmentation）；策略层用 [[ACT (Action Chunking Transformer)]] / BC；recovery 思路接近 DAgger 但全自动
- **借鉴意义**: 跟 [[MimicGen]] 是同一条线上的下一代——MimicGen 做空间扰动数据生成，PGDG 加上"物理可行性 + 失败恢复 mode 覆盖"。对做 single-demo / few-shot 数据增广的工作直接对标
- **锐评**: 思路扎实——把"physically plausible recovery"做成显式目标确实比 MimicGen 那种纯几何扰动更聪明。但有几点要确认：(1) sampler-curator 迭代收敛保证？论文用 DPP 选样本但没给收敛性；(2) RotateBox-Pitch 这种任务的 38% → 93% 听着夸张，但 baseline 38% 已经说明任务对 BC 很难，可能 baseline 太弱；(3) zero-shot real-world transfer 的成功率绝对值多少？没看到具体数字。整体是可信的 incremental 工作，跟 dexmate 那边的工程化方向匹配。👀

- **核心方法**: SafePBDS（Safe Pullback Bundle Dynamical System）在不同几何流形（$\mathbb{R}^7$ 关节空间 / $\mathrm{SE}(3)$ 末端位姿）之间做几何一致的安全运动策略。两个核心 trick：(1) pullback [[CBF|control barrier function]] 把"在 task manifold 上的安全约束"线性化为"configuration manifold 加速度上的线性约束"；(2) task manifold action interface 允许高层 policy 注入低维残差，0 输入就回到 autonomous 行为，安全性始终被 CBF 保住。
- **对比方法/Baselines**: 对比 PBDS（无 safety 版本）、纯 [[CBF]]、ECBF；跟 [[Diffusion Policy]] / [[ACT (Action Chunking Transformer)]] 等学习型 policy 互补，不是替代
- **借鉴意义**: 对"learning-based policy + safety filter"那条路有意义——SafePBDS 可以作为 [[Diffusion Policy]] / VLA 输出后的安全 wrapper，零输入时保持原行为，高风险时强制走流形上的安全 acceleration。比传统 joint-level CBF 更适合 dexterous 操作
- **锐评**: 控制理论扎实但门槛高——pullback bundle 那一套是 differential geometry 老炮儿的语言，对深度学习背景的读者很不友好。论文写得严谨但实验偏 demo 性质，真要在 [[OpenVLA]] / Diffusion Policy 上做 wrapper 实验估计还要二次开发。属于"思想价值 > 即用价值"的工作。👀
- **关联笔记**: [[CBF]]、[[14-安全与鲁棒性]]、[[Diffusion Policy]] 可以作为上层 policy
- 💡 **想精读？** 运行：`读一下 SafePBDS`
