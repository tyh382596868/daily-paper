### 1. LeWorldModel: Stable End-to-End Joint-Embedding Predictive Architecture from Pixels
- **链接**: [arXiv](https://arxiv.org/abs/2603.19312) | [PDF](https://arxiv.org/pdf/2603.19312)
- **来源**: 🔥 HF Trending，⬆️ 44

> ⏪ **再推提醒**：这篇在 2026-05-09 推荐过

- 📒 **已有笔记**: [[LeWM]] — 直接看笔记，不再重复解释。简单说：第一个能从原始像素端到端稳定训练的 JEPA，只用两个 loss（next-embedding prediction + 高斯正则），把可调超参从 6 个砍到 1 个，~15M 参数单卡几小时训完，planning 比 [[DINO-WM]] 类基础模型快最多 48×。
- **锐评**: 这才是 world model 该有的样子——别人靠 EMA、预训练 encoder、6 项 loss 才不坍塌，它两项 loss 搞定。对我们做 [[JEPA]] / latent world model 的人，这是一个干净的 baseline 和反例：复杂 loss 设计可能根本不是必需的。要警惕的是规模——15M 参数 + 2D/3D control 任务，跟真实机器人差着量级，"latent 编码物理结构"的探针实验做得好看，但能不能撑起 manipulation 级别的动力学还得看后续。
- **关联笔记**: [[JEPA]]、[[DINO-WM]]、[[PLDM]]、[[世界模型]]

### 2. 3D-Belief: Embodied Belief Inference via Generative 3D World Modeling
- **作者**: Yifan Yin, Zehao Wen, Suyu Ye, Jieneng Chen, Zehan Zheng, Nanru Dai, Haojun Shi, Aydan Huang, Zheyuan Zhang, Alan Yuille, Jianwen Xie, Ayush Tewari
- **机构**: Johns Hopkins University、Lambda、University of Cambridge
- **链接**: [arXiv](https://arxiv.org/abs/2605.11367) | [PDF](https://arxiv.org/pdf/2605.11367)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2605.11367v1/x1.png)

- **核心方法**: 输入是 agent 在部分可观测环境下采到的若干帧观测，输出是一个**显式的、可操作的 3D belief**——不是未来帧、不是新视角图像，而是对未观测 3D 世界的结构化猜测，并随新观测在线更新。架构上用 [[扩散变换器|diffusion]] 训练（"Diffusion Training" 一节），骨干借鉴 [[VGGT]] 做几何编码、[[SigLIP]] 做语义；关键能力是：空间一致的场景 memory、多假设 belief 采样、序贯 belief 更新、语义引导的未观测区域预测。与现有方法的核心区别——把不确定性直接表示在 3D 空间里，而不是 pixel 空间里渲染"可能看到什么"。
- **对比方法/Baselines**: 对比了 [[VGGT]]（几何重建基线）、NWM（navigation world model）、SPOC/THOR 系导航策略；评估用自建的 3D-CORE benchmark + ai2thor 风格的 object navigation，指标含 FVD、SR、SPL。
- **借鉴意义**: 对做 world model 的人是个值得认真想的视角转换——"world model 不该只渲染所见，而该维护对未见的信念"。这跟 active perception / POMDP belief tracking 是老话题，但用生成式 3D 模型来做 belief 是新瓶。能不能 scale 到真实机器人、3D belief 表示够不够 actionable，是关键疑问。
- **关联笔记**: [[世界模型]]、[[VGGT]]、[[扩散变换器]]
- 💡 **想精读？** 运行：`读一下 3D-Belief: Embodied Belief Inference via Generative 3D World Modeling`

### 3. HorizonDrive: Self-Corrective Autoregressive World Model for Long-horizon Driving Simulation
- **作者**: Conglang Zhang 等
- **机构**: 武汉大学、东京大学、地平线 Horizon Robotics、清华大学、中科大、香港中文大学
- **链接**: [arXiv](https://arxiv.org/abs/2605.11596) | [PDF](https://arxiv.org/pdf/2605.11596)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2605.11596v1/x1.png)

- **核心方法**: 输入是历史驾驶帧 + 结构化场景/驾驶行为条件，输出是长时域自回归生成的驾驶视频（支持分钟级 rollout，且内存有界）。两步走：(1) **SRR（scheduled rollout recovery）**——训练 base model 从"被自己预测污染过的历史"里重建 ground-truth 未来帧，得到一个在长 AR rollout 下不漂移的 teacher；(2) 把这个 rollout-capable teacher 通过 AR rollout 延展，给出无界时域的分布匹配监督，再用 **TRD（teacher rollout DMD）**把短窗口 student 蒸馏对齐到它，实现实时部署。核心区别于现有 AR 蒸馏：不靠 frame sink、不靠 student 端退化训练，而是直接让 teacher 自己学会"在自己的预测上稳住"。
- **对比方法/Baselines**: 对比 Self-Forcing 等 AR 蒸馏方法；用了 [[扩散变换器|DiT]] 类视频生成骨干、DMD（distribution matching distillation）蒸馏；在 nuScenes 上 FID −52%、FVD −37%，并降低 ARE / DTW。
- **借鉴意义**: "teacher 漂移污染监督"是所有 autoregressive world model 的通病，SRR 这种"先把 teacher 训稳再蒸馏"的思路可以迁移到 robotics 的视频世界模型（[[CtrlWorld]] / [[IRASim]] 这类）。缺点是评估只在驾驶域，nuScenes 这种相对结构化的场景，换到杂乱 manipulation 场景能不能稳住是问号。
- **关联笔记**: [[世界模型]]、[[视频扩散模型]]、[[扩散变换器]]
- 💡 **想精读？** 运行：`读一下 HorizonDrive: Self-Corrective Autoregressive World Model for Long-horizon Driving Simulation`

### 6. CapVector: Learning Transferable Capability Vectors in Parametric Space for Vision-Language-Action Models
- **作者**: Wenxuan Song, Han Zhao, Fuhao Li, Ziyang Zhou, Xi Wang, Jing Lyu, Pengxiang Ding, Yan Wang, Donglin Wang, Haoang Li
- **机构**: HKUST(GZ)、浙江大学、西湖大学、清华大学、北京智源 BAAI
- **链接**: [arXiv](https://arxiv.org/abs/2605.10903) | [PDF](https://arxiv.org/pdf/2605.10903)
- **来源**: 🔥 HF Trending，⬆️ 0

![](https://arxiv.org/html/2605.10903v1/x1.png)

- **核心方法**: 输入是预训练 VLA + 小规模任务集，输出是一组"capability vector"（参数空间里的差向量）和一个增强后的 meta model。两阶段：训练前，在小任务集上分别用"带辅助目标 SFT"和"普通 SFT"训到收敛，得到两个模型，参数差即 capability vector，把它加回预训练参数得到 capability-enhanced meta model；训练中，对下游任务做标准 SFT，但加一个轻量的正交子空间正则（[[LoRA]] 风格），防止下游适配把这些能力洗掉。核心区别于直接做带辅助目标的 SFT——把"增强通用能力"和"拟合任务动作分布"两个目标在参数空间解耦，避免每次下游训练都背着辅助 loss 的算力开销。
- **对比方法/Baselines**: 对比 [[OpenVLA]]-OFT、LaRA、StarVLA 等辅助目标微调方法；在 [[LIBERO]] 和 RoboTwin 上做 ID/OOD/versatility/real-world 五组实验。
- **借鉴意义**: task arithmetic / model merging 在 LLM 圈玩了很久，搬到 VLA 上算 incremental。如果你正在被"辅助目标 SFT 太贵"困扰，这个 capability vector 复用思路能省点算力；否则没什么必看的。
- **关联笔记**: [[OpenVLA]]、[[LIBERO]]、[[LoRA]]

### 7. RankQ: Offline-to-Online Reinforcement Learning via Self-Supervised Action Ranking
- **作者**: Andrew Choi, Wei Xu
- **机构**: 未知（作者标注 1, †，机构未在页面给出）
- **链接**: [arXiv](https://arxiv.org/abs/2605.11151) | [PDF](https://arxiv.org/pdf/2605.11151)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2605.11151v1/images/toy_example.png)

- **核心方法**: 输入是离线数据集 + 后续在线交互，输出是一个 offline-to-online 的 Q-learning 目标。核心：在标准 TD learning 之上加一个**自监督多项 ranking loss**，强制 Q 函数对动作做结构化排序——学的是动作之间的相对优劣，而不是像 [[CQL]] 那样统一压低所有未见动作（那本质是个 BC anchor，数据次优时会拖累在线提升）。这样 Q 的梯度方向被引导指向更高质量行为。在视觉机器人场景里，用它对预训练 [[VLA]] 做低数据量 offline-to-online 微调。
- **对比方法/Baselines**: 对比 7 个 offline RL 方法（含 [[CQL]]、QL 类）；用 [[SAC]]-Flow 的 formulation；在稀疏奖励 D4RL 上评估，视觉机器人上比次优方法仿真成功率高 42.7%（低数据）/ 13.7%（高数据），真机叠方块从 43.1%→84.7%。
- **借鉴意义**: 对做 VLA + RL 微调的人挺实用——"learn to rank actions 而非 penalize OOD actions"这个角度避开了 BC anchor 的老毛病，43%→85% 的真机数字也不算小。要存疑的是 ranking loss 的多项设计（论文有附录）会不会很娇气、对 reward 稀疏程度敏感；真机实验只有叠方块一个任务，覆盖面薄。
- **关联笔记**: [[SAC]]、[[2-强化学习|强化学习]]、[[OpenVLA]]
- 💡 **想精读？** 运行：`读一下 RankQ: Offline-to-Online Reinforcement Learning via Self-Supervised Action Ranking`

### 8. See What Matters: Differentiable Grid Sample Pruning for Generalizable Vision-Language-Action Model
- **作者**: Yixu Feng, Zinan Zhao, Yanxiang Ma, Chenghao Xia, Chengbin Du, Yunke Wang, Chang Xu
- **机构**: 未知（代码仓库 github.com/Fediory/Grid-Sampler，疑似悉尼大学相关）
- **链接**: [arXiv](https://arxiv.org/abs/2605.11817) | [PDF](https://arxiv.org/pdf/2605.11817)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2605.11817v1/assets/fig1.png)

- **核心方法**: 输入是 VLA 视觉 encoder 里的 visual token，输出是大幅压缩后（保留 <10% 原始 token）但保住关键几何信息的 token 集合。核心是 **GridS（Differentiable Grid Sampler）**：一个即插即用模块，不做离散的"丢弃 token"，而是把压缩当成几何感知的连续 token 重采样——自适应预测一组最少的显著坐标点，用可微双线性插值在那些位置取特征，从而保住接触点这类关键空间细节。和 joint optimization 一起训练。区别于现有 token pruning：那些方法越激进压缩就越会丢掉几何细节导致性能崩，GridS 用"连续重采样"打破这个 trade-off。
- **对比方法/Baselines**: 对比标准 VLA 的 token pruning 方法；在 [[LIBERO]] benchmark + 真实机器人平台上验证，骨干涉及 [[SmolVLA]]、ALOHA；号称 FLOPs −76% 且成功率不掉。
- **借鉴意义**: VLA 实时部署的算力瓶颈是真痛点，"把 pruning 重新理解为可微连续重采样"是个漂亮角度——对做 efficient VLA / 边缘部署的人值得看。要质疑的是：<10% token 还能"无损"，那原来 90% token 在干嘛？这暗示当前 VLA 视觉表示冗余度极高，但也可能意味着 LIBERO 这种 benchmark 太简单，换到需要精细几何的真实任务上"无损"会不会破功。
- **关联笔记**: [[LIBERO]]、[[OpenVLA]]
- 💡 **想精读？** 运行：`读一下 See What Matters: Differentiable Grid Sample Pruning for Generalizable Vision-Language-Action Model`

### 9. Beyond World-Frame Action Heads: Motion-Centric Action Frames for Vision-Language-Action Models
- **作者**: Huoren Yang 等
- **机构**: 西安交通大学、深圳先进技术大学
- **链接**: [arXiv](https://arxiv.org/abs/2605.11809) | [PDF](https://arxiv.org/pdf/2605.11809)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2605.11809v1/x1.png)

- **核心方法**: 输入是 VLA 骨干给出的特征，输出是动作命令——但不在固定 world frame 里预测。**MCF-Proto** 是个轻量 action head：每步先预测一个旋转 R_t ∈ SO(3)，在变换后的局部坐标系里用一组 prototype 组合出动作，再映射回 world frame 做端到端训练，全程只用标准 demonstration、不需要额外监督。结果是涌现出稳定结构——学到的局部坐标系轴向跟末端执行器运动方向强相关，动作表示变得更紧凑（少数主方向 + 共享 prototype 组织），在几何扰动下更鲁棒。区别于主流 VLA action head：那些直接在固定世界坐标系回归动作命令，这个给 action head 加了轻量几何 + 组合结构。
- **对比方法/Baselines**: 对比 [[OpenVLA]]、OFT、SmolVLA 等的标准 action head；在 [[LIBERO]] 和 LIBERO-plus 上做主实验，行为克隆（[[Action Chunking|BC]]）范式。
- **借鉴意义**: "action head 的坐标系/参数化"长期被忽视，这篇说明改一改就能涨鲁棒性——对做 VLA action head 设计的人有启发，prototype + 局部 frame 的组合可以借鉴。但 contribution 偏小（一个 head 模块），实验只到 LIBERO 系，没看到真机数字，"涌现结构"的分析多于实用收益。
- **关联笔记**: [[OpenVLA]]、[[LIBERO]]、[[Action Chunking]]
- 💡 **想精读？** 运行：`读一下 Beyond World-Frame Action Heads: Motion-Centric Action Frames for Vision-Language-Action Models`

### 10. Dynamic Execution Commitment of Vision-Language-Action Models
- **作者**: Feng Chen 等
- **机构**: 阿德莱德大学、四川大学、上海交通大学、莫纳什大学、浙江大学、帝国理工
- **链接**: [arXiv](https://arxiv.org/abs/2605.11567) | [PDF](https://arxiv.org/pdf/2605.11567)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2605.11567v1/x1.png)

- **核心方法**: 输入是任意 chunked-action VLA 的动作 chunk，输出是动态决定的"执行多少步再重规划"。**A3（Adaptive Action Acceptance）**把动态执行承诺重构成一个 self-speculative prefix verification 问题：先用 group sampling 算一个 trajectory-wise consensus 分数，选一个代表性 draft，再做下游验证——(1) consensus-ordered conditional invariance：低 consensus 的动作，看它在"以高 consensus 动作为条件重新解码"后是否一致；(2) prefix-closed sequential consistency：只接受从开头起最长的连续已验证动作段。最后执行 horizon 就是同时满足这两条的最长可验证前缀。区别于固定执行 horizon 的启发式：那些忽略了"预测可靠性是状态依赖的"，在动态/OOD 场景下脆。
- **对比方法/Baselines**: 跨多个 VLA 模型和 benchmark（[[LIBERO]]、MetaWorld、ManiSkill 系 StackCube、EveryDayVLA）；对比固定 horizon 的 [[Action Chunking|action chunking]] 基线。

### 11. Overcoming Dynamics-Blindness: Training-Free Pace-and-Path Correction for VLA Models
- **作者**: Yanyan Zhang, Chaoda Song, Vikash Singh, Xinpeng Li, Kai Ye, Zhe Hu, Zhongzhu Pu, Yu Yin, Vipin Chaudhary
- **机构**: Case Western Reserve University、香港理工大学、清华大学
- **链接**: [arXiv](https://arxiv.org/abs/2605.11459) | [PDF](https://arxiv.org/pdf/2605.11459)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2605.11459v1/x1.png)

- **核心方法**: 输入是冻结 VLA 给的 baseline 动作 chunk Δp + 一个动力学传感器给的动态信号 (v, d̂)，输出是修正后的动作 chunk。**PPC（Pace-and-Path Correction）**：从一个二次代价函数（per-chunk 跟踪误差 + 修正代价）出发，最优解正交分解成两个闭式 channel——Pace Channel 把 v·d̂ 的平行分量吸收成一个时间压缩因子 α*（沿规划方向压缩执行），Path Channel 吸收正交分量成一个空间偏移。再套一个 Hierarchical 2-EMA latch stabilizer 保 chunk 间一致性。完全免训练、闭式、wrap 任意 chunked VLA。区别于现有方法：要么得重训、要么有延迟瓶颈和 chunk 间抖动。

- **借鉴意义**: VLA 单帧观测 → "动力学盲"这个问题点得准，闭式两 channel 分解优雅、零训练成本对落地友好——对做 VLA 鲁棒性 / 动态场景的人值得看。但要清醒：它需要一个"动力学传感器"提供 (v, d̂)，这个信号哪来的、对它的噪声有多敏感是关键；MoveBench 是自建的、专门"隔离运动"，对自家方法可能天然有利。
- **关联笔记**: [[Action Chunking]]、[[EMA]]

### 12. DreamAvoid: Critical-Phase Test-Time Dreaming to Avoid Failures in VLA Policies

- **链接**: [arXiv](https://arxiv.org/abs/2605.11750) | [PDF](https://arxiv.org/pdf/2605.11750)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2605.11750v1/x2.png)

- **核心方法**: 输入是执行中的 VLA 策略状态，输出是在关键阶段被"梦境评估"筛过的动作。**DreamAvoid**：(1) Dream Trigger 判断当前是否进入 critical phase；(2) Action Proposer 从 VLA 采多个候选 action chunk；(3) Dream Evaluator（用混合数据训练——成功、失败、边界 case）对每个候选"梦"出短时域未来、评估其 value、选最优动作。再加一个自主边界学习范式（autonomous boundary learning），让系统不断细化"成功与失败之间的微妙边界"。区别于现有 VLA：现有 VLA 几乎只用成功 demonstration 训练，对关键阶段的失败没有显式意识；这篇在 inference time 引入了"想象失败、避开它"的能力。

- **关联笔记**: [[世界模型]]、[[SimplerEnv]]、[[LIBERO]]、[[具身推理]]

- **核心方法**: 输入是局部观测，输出是未来 waypoint。**NavOL** 是个 online imitation learning 范式：在预训练的导航 [[Diffusion Policy|diffusion policy]] 基础上，做 rollout-update 循环——rollout 时策略在仿真器里行动，并查询一个有全局环境特权访问的 global planner 拿最优路径段当 GT 轨迹标签；update 时用在线采的 (observation, trajectory) 对训练策略。这个在线模仿循环去掉了 reward 设计、提升学习效率、用"在自己探索的 rollout 上训练"缓解 distribution shift。基于 IsaacLab，50 个场景 8×RTX4090，每小时采 >2000 条轨迹（每条 >400 步），还提了个室内视觉导航 benchmark。
- **对比方法/Baselines**: 对比 NavDP、ViPlanner 等导航策略；在 NavDP benchmark + 自建 benchmark + 真机上评估；指标 SPL、SR。
- **借鉴意义**: DAgger 思路（在线查询专家修正 distribution shift）在导航上的又一次应用，加了"diffusion policy + IsaacLab 大规模并行采数据"的现代化包装。对做导航的人可能有点用，但方法本身不新——"用特权 global planner 当老师"就是经典的 privileged learning。
- **关联笔记**: [[Diffusion Policy]]、[[5-导航与定位|导航与定位]]

### 21. EvoNav: Evolutionary Reward Function Design for Robot Navigation with Large Language Models
- **作者**: Zhikai Zhao, Chuanbo Hua, Federico Berto, Zihan Ma, Kanghoon Lee, Jiachen Li, Jinkyoo Park
- **机构**: 未知（机构未在页面给出，疑似 KAIST 相关）
- **链接**: [arXiv](https://arxiv.org/abs/2605.11859) | [PDF](https://arxiv.org/pdf/2605.11859)
- **来源**: 📄 arXiv 关键词检索

- **核心方法**: 输入是导航任务描述，输出是自动设计的 RL reward 函数。**EvoNav**：用 LLM 在进化框架里生成 reward 候选，为了绕开"训完整策略评估每个候选太贵"的问题，用一个 progressive 三阶段 warm-up-boost 评估——先用 analytical proxy（小数据集 + 解析规则）低成本筛，再 lightweight rollout，最后才 full policy training，从而在有效反馈下做算力高效的探索。结果说比手工设计的 RL reward 和 SOTA reward design 方法都强。
- **对比方法/Baselines**: 对比手工 RL reward、SOTA reward design 方法（Eureka 类）。
- **借鉴意义**: 这就是 Eureka（LLM 设计 reward）搬到导航 + 加了个"渐进式廉价评估"省算力。对做导航 RL 且苦于 reward shaping 的人有点用，但方法是已有范式的领域迁移，新意主要在那个三阶段评估上。对 embodied/world model 方向基本无关。
- **关联笔记**: [[5-导航与定位|导航与定位]]、[[2-强化学习|强化学习]]

### 22. VidSplat: Gaussian Splatting Reconstruction with Geometry-Guided Video Diffusion Priors
- **作者**: Jimin Tang, Wenyuan Zhang, Junsheng Zhou, Zian Huang, Kanle Shi, Shenkun Xu, Yu-Shen Liu, Zhizhong Han
- **机构**: 清华大学、快手科技、Wayne State University
- **链接**: [arXiv](https://arxiv.org/abs/2605.11424) | [PDF](https://arxiv.org/pdf/2605.11424)
- **来源**: 📄 arXiv 关键词检索

![](https://arxiv.org/html/2605.11424v1/x1.png)

- **核心方法**: 输入是稀疏视角（甚至单张图）的图像，输出是完整的 3D Gaussian Splatting 场景。**VidSplat** 是个免训练的生成式重建框架，用强大的视频扩散先验迭代合成补充输入覆盖的 novel view。两个关键：(1) 3D 一致生成——免训练的 stage-wise denoising，用渲染出的 RGB 和 mask 自适应引导去噪方向朝向底层几何；(2) 增强重建——迭代机制：采相机轨迹、探索未观测区域、合成 novel view、用置信度加权 refine 来补充训练。区别于现有稀疏视角重建：那些靠增强多视角一致性产生合理表面，但推不出超出输入覆盖的遮挡/弱约束区域，VidSplat 用视频扩散先验"脑补"那些区域。
- **对比方法/Baselines**: 对比稀疏视角表面重建 / 稀疏输入 NVS 方法（[[扩散变换器|NeRF]] 系、TrajectoryCrafter 等）；在 Tanks&Temples 等常用 benchmark 上评估。
- **借鉴意义**: 对做 3DGS / 稀疏重建的人有用——"用视频扩散先验补未观测区域"是当前热门套路，免训练 + stage-wise 几何引导的去噪策略可以借鉴。但离 robotics / embodied 比较远，放进来主要是因为命中了"video diffusion"关键词；对我们做 world model 的人，能借的只有"diffusion prior 当 3D 补全器"这个抽象思路。
- **关联笔记**: [[视频扩散模型]]、[[扩散变换器]]
